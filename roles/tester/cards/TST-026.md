id: TST-026
rule: Fuzz every input that reaches an interpreter, using automated testing including fuzzing.
why: Injection happens when untrusted input reaches an interpreter.
applies-when: a test covers an input that reaches a query, shell or template
not-when: a live site, where the tester does not send attack input and uses a local or test instance
example: a search box feeds a SQL query, so the test fuzzes it with quote characters on a test instance and checks for database errors
mode: code
trigger: when a test covers a field that reaches a query or interpreter
