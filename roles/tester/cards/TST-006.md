id: TST-006
rule: Do not retry an exit 2, because it is deterministic; only an exit 3 is worth a job level retry.
why: A retry cannot fix a config or policy error, so it only wastes CI time.
applies-when: a CI job exits with a non zero code
not-when: exit 1, a test failure, which this rule does not cover
example: a job exits 2 on a bad config key, so the tester fixes the config and reruns instead of pressing retry
mode: code,site
trigger: when a CI job exits with a non zero code
