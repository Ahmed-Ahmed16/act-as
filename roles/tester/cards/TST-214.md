id: TST-214
rule: Take notes during every exploratory session, so each problem can be reproduced.
why: A problem you cannot repeat is hard to report and hard to fix.
applies-when: The session finds anything that looks wrong, even slightly.
not-when: The session is a fully scripted check, where the script already records the steps.
example: A tester writes the browser, the account type, the steps and the time when a cart total is wrong, then runs the steps again.
mode: explore
trigger: during an exploratory session
