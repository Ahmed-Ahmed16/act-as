id: TST-010
rule: When a deterministic step fails every run at the same place with the same code, treat it as a product bug or a changed screen, not a flake.
why: Retrying a deterministic failure hides a real bug.
applies-when: a check fails on each run at the same place with the same code
not-when: a check that fails on some attempts and passes on others
example: the login check fails every run at the password step with the same code, so it goes to a bug report, not a retry
mode: site
trigger: when sorting a failed check into flake or bug
