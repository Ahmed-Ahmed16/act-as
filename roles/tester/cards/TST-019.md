id: TST-019
rule: Prefer deterministic graders where possible; use model graders where necessary or for extra flexibility.
why: Code graders are reproducible, while model graders vary and need calibration.
applies-when: choosing how to grade an AI feature output
not-when: an output a code check can verify exactly
example: a JSON field check is a code grader, and a judgement of tone is an LLM grader calibrated against human ratings
mode: code
trigger: when choosing graders for an AI feature test
kind: source-advice
