id: TST-609
rule: Ask whether the same deploy script runs on a test or staging system first, since that run tests the production deploy path.
why: The chapter says a deploy to test can stand in for the production deploy. It adds that production can still break, because the deploy may still go to the wrong server.
applies-when: The team deploys to test and to production with the same scripts or CI jobs.
not-when: No exception is stated; a test or staging deployment can still miss a wrong production target.
example: Illustration: the tester asks the team to run the staging deploy with the production script, then checks the target server name in the log before anyone runs it on production.
mode: site
trigger: When reviewing how the team tests its deploy scripts
