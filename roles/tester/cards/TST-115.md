id: TST-115
rule: When tests are slow, swap the slow dependency for a fast fake before you share state between tests.
why: Shared state makes tests interfere with each other, which causes failures that come and go.
applies-when: A test run is too slow, and the slow part is a database or another remote component.
not-when: The slow part is the code under test and a fake would not measure it; profile first.
example: A suite that writes to a real database checks most logic against an in memory fake repository, and keeps one real database test separate.
mode: code
trigger: when the test run is slow and someone proposes a shared fixture
kind: source-advice
