id: TST-023
rule: Test retrieved content, tool output and memory as prompt injection inputs, not only typed user input.
why: Input from retrieved content and tool output can alter the model's behavior in ways the developer did not intend.
applies-when: an AI feature reads retrieved documents, tool results or memory
not-when: a feature whose model sees only a fixed prompt and typed input
example: a support bot reads ticket text, so a test puts an instruction inside a ticket and checks the bot does not obey it
mode: code,explore
trigger: when a test feeds retrieved or tool text to an AI feature
kind: source-advice
