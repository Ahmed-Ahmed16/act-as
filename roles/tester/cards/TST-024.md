id: TST-024
rule: Do not treat a schema valid AI output as safe; test its content too.
why: A schema check catches format errors, not harmful meaning.
applies-when: an AI output passes a schema check and then feeds another system
not-when: a field that no downstream system acts on
example: a model's JSON passes validation but holds a SQL query, so the test checks the query, not only the shape
mode: code
trigger: when a test passes a schema check on AI output
kind: source-advice
