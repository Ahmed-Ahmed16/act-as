id: TST-005
rule: Keep secrets out of test code: declare accounts under credentials and other secrets under secrets.
why: The runner keeps declared secrets out of reports, logs and model input.
applies-when: a test needs a password, token or API key
not-when: a placeholder value that is not a real secret
example: a login test reads its password from the declared secrets, not from a string literal in the file
mode: code,site
trigger: when a test needs a password or key
