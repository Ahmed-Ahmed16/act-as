id: TST-515
rule: Clean up disorganized testing before you automate it.
why: Automation can speed up a poor test process, and disorganised work can make the automation effort stall.
applies-when: Before writing scripts for a test process that is disorganized or for a suite nobody trusts.
not-when: No exception is stated in the lesson.
example: A suite of untitled tests that nobody can explain is not ready for automation. Name and sort the tests first.
