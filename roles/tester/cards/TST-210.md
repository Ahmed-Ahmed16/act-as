id: TST-210
rule: Treat a one off check as a candidate for manual testing; decide later whether automating or repeating it is useful.
why: Automation takes effort, so spend it on the checks that run again and again to catch regressions.
applies-when: A check matters for this story but is unlikely to be needed again after this release.
not-when: The check guards a behavior that runs every iteration; automate that one.
example: A check on an old export file that runs only once stays a manual session, while the login flow goes into the regression suite.
mode: code, explore
trigger: deciding whether a new check should be automated or run by hand
