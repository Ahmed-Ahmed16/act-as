id: TST-203
rule: Run exploratory sessions against the working product to find the serious bugs that scripted checks miss.
why: A script only confirms what someone already thought of, while a tester using judgment finds the problems nobody wrote down.
applies-when: A story passes its written examples and the team needs to know whether it works for a real user.
not-when: The same check has to run on every build; automate that instead.
example: After a coupon story passes its examples, the tester spends a session mixing coupons with returns and finds a case the examples never covered.
mode: explore
trigger: a story passes its examples and needs a real user check
kind: source-advice
