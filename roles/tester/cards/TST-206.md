id: TST-206
rule: Test business rules through the API or the code below the page when you can, not through the screen.
why: These checks are cheaper to write and stay steady when the page layout changes.
applies-when: The business rule can be reached through a service call or an API.
not-when: The point is the page itself, such as layout or the text a user sees; then a page check is the right tool.
example: A shipping cost rule is checked by calling the service that returns the cost, not by filling in the checkout form.
