rule: For software sold for resale, include the 10 likely most serious criticisms in the release report.
why: It shows the risks before a reviewer finds them and keeps you a critic of the software, not its cheerleader.
applies-when: Writing a release report for software sold for resale.
not-when: The lesson gives this advice for resale software; it does not set the same rule for other releases.
example: A release report lists the slow search on large catalogs, 1 open cart bug, and the untested mobile layout, each with what was tested.
