rule: Start each exploratory session with a charter that names the area to explore.
why: A charter keeps the session on one target, so the tester does not chase whatever looks interesting.
applies-when: Any exploratory session.
not-when: A check that must give the same result every run; write a script for that.
example: Charter: explore the discount field on the cart page with each shipping option, for 60 minutes.
