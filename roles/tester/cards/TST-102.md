id: TST-102
rule: A test must decide pass or fail on its own, so a clean run needs no person to read output.
why: If a person has to read printed output, the test does not run unattended and a wrong result can slip past.
applies-when: Writing any test, including a test that prints values or runs a script.
not-when: A quick exploration script that the tester reads by hand on purpose; that is explore work, not a test to keep.
example: A check that prints "total is 42" and waits for a person to compare it is replaced by an assertion that fails when the total is not 42.
mode: code
trigger: before writing a test, and when reviewing a test that prints values but has no assertion
