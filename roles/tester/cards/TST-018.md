id: TST-018
rule: It is often better to grade what the agent produced than the path it took.
why: Path checks punish valid solutions that take a different route.
applies-when: writing a grader for an agent task
not-when: a path that is itself the safety rule, such as a banned tool call
example: a grader checks the saved file's content, not whether the agent opened the file first
