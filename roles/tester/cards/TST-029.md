id: TST-029
rule: Before testing for SQL injection, list every input field whose value could be used to build a SQL query.
why: The first test objective is to identify the injection points.
applies-when: planning SQL injection testing
not-when: a live site without the user's approved test scope
example: a product filter parameter is listed as a query input before the tester tries any payload on it
