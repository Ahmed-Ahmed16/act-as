id: TST-009
rule: When a locator matches two nodes, narrow it with filter, first, nth or a scope instead of picking one at random.
why: The runner requires exactly one match per action, read or assertion.
applies-when: a locator returns more than one element
not-when: a read that is meant to count several elements
example: a Delete button appears in every row, so the test scopes to the row named Invoice 12 before clicking
mode: site
trigger: when a locator fails with more than one match
