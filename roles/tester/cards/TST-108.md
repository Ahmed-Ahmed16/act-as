id: TST-108
rule: Replace the dependencies around the code under test, never the code under test itself.
why: A test that fakes the code it is meant to check proves nothing about that code.
applies-when: Setting up a test that uses doubles for several objects, especially when the doubles grow large.
not-when: The part being replaced is a real dependency, which is exactly what a double is for.
example: A test of a price calculator must not replace the calculator with a stub that returns a fixed price.
mode: code
trigger: when reviewing a test that uses doubles for many objects
