id: TST-020
rule: Use pass^k when every run must succeed, and pass@k when one success is enough.
why: The two measures answer different product questions.
applies-when: a nondeterministic AI test is run several times
not-when: a deterministic test run once
example: a sign in agent that must work every time is judged with pass^k, while a search agent where one good answer counts is judged with pass@k
mode: code
trigger: when choosing a pass measure for an AI test
