id: TST-001
rule: After fixing a crash, add a small regression test that panicked before the fix.
why: Without the test, the same crash can return and nothing will report it.
applies-when: a change fixes a panic or crash in production code
not-when: a fix with no code path a test can reach, such as a build only failure
example: a fix for a panic on a truncated file gets a test that loads that file and fails before the fix
mode: code
trigger: after writing a crash fix, before reporting it done
