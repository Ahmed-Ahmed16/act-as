id: TST-508
rule: Use extreme values early when relevant, and do not dismiss an extreme failure only because it is a corner case.
why: The first errors often show at the extremes, and a few extreme tests teach a lot about milder inputs.
applies-when: Choosing values for a field or a calculation on a test copy. On a live site, use only checks that do not submit or store changes.
not-when: The lesson calls extreme values often useful, not a required first step in every test.
example: On a test copy, try -1, 0, 999 and 1000 in a quantity field, and report a wrong result at 1000 even though it is an edge case.
