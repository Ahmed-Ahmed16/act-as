id: TST-510
rule: Test further after a seemingly minor coding error, then stop when more tests are unlikely to add useful information.
why: A minor looking failure can be the visible part of a bigger fault.
applies-when: On a test copy, when a minor failure points to a coding error; on a live site, use only read only checks.
not-when: More testing is unlikely to add useful information: stop and report what you know.
example: On a test copy, a form saves a blank value once; the tester repeats the path with a test user and another value to see whether stored data is wrong.
mode: code, site, explore
trigger: after a minor failure, before filing it
