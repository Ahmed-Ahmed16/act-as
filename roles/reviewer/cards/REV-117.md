id: REV-117
rule: If the merge base equals the PR head, the PR is already merged. Use the base commit GitHub recorded for the PR as the left side of a 3 dot diff to the frozen head (the command proved in ticket 01). If that cannot be read or checked, write "not checked: PR already merged, base not proved" and make no count.
why: After a merge the branches have moved, so the merge base is no longer a usable base. GitHub keeps the base commit it recorded, even when the branch is deleted.
applies-when: The merge base of the base branch head and the PR head equals the PR head.
not-when: none
example: In invented PR 103 for owner/shop, merged last week, the merge base equals its head. The reviewer reads the recorded base commit and runs git diff <recorded base>...<head> for every comparison.
