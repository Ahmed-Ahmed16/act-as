id: REV-510
rule: Count the layers and hidden state a reader must keep in mind when reading the changed code.
why: A review guide for coding agents names layers and hidden state as the load on a reader of hard to trace code.
applies-when: The PR adds shared or static state, a value that one call sets and another reads, or an extra layer a reader must pass through to follow the code.
not-when: The state is passed in or named at the top of the method, so a reader sees it.
example: In invented PR 101 for owner/shop, Cart::applyCoupon() reads $this->prices, which only Cart::loadPrices() sets, and nothing says so. The reviewer writes this as hidden state, with the file and line of both methods.
