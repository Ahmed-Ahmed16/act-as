id: REV-411
rule: Read changes to the test config, skipped tests, excluded groups, CI workflow files and Composer test scripts. A PR can stop tests from running without deleting a test file.
why: PHPUnit can exclude a whole group or skip a test, and a CI workflow can be skipped by its filters. Composer scripts decide which command runs the tests. Each is a way to drop tests quietly.
applies-when: A PR touches phpunit.xml, a test group or skip mark, a CI workflow file, or the scripts section of composer.json.
not-when: none
example: In invented PR 101 for owner/shop, phpunit.xml gets a new exclude group "slow" and 4 payment tests carry that group. No test file is deleted, but the reviewer reports that the 4 tests no longer run.
mode: health, full
trigger: When checking whether tests still run (H6)
kind: source-advice
