id: REV-339
rule: A response or export carries only the fields the screen needs, picked by name. It never sends tokens, codes or other users' data.
why: OWASP says to choose by name which fields of an object go out, instead of calling a catch all method like to_json(), and to send no more data than needed.
applies-when: A changed API resource, toArray, json response, $hidden list or export returns a model.
not-when: The model has only fields that every reader may see.
example: In invented PR 101 for owner/shop, the API returns response()->json($user). The JSON includes the api_token and phone number, which the page never shows.
mode: security, full
trigger: When a changed response or export returns a model
