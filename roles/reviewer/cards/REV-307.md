id: REV-307
rule: When request ids go into sync, attach or a similar relation call, check which related rows the user is allowed to link, and know that sync removes every id that is not in the list.
why: Laravel says sync takes a list of ids and removes any id that is not in the list from the link table. OWASP API3 says to let a client change only what it is meant to change, and a list of ids from the request should be held to that.
applies-when: A changed line passes ids from the request to sync, attach, detach, toggle, createMany or a similar call.
not-when: The ids come from the server, not from the request.
example: In invented PR 101 for owner/shop, the user edit form sends role_ids and the code runs $user->roles()->sync($request->role_ids). A user adds the admin role id to the list and gains admin rights.
mode: security, full
trigger: When request ids go into a relation call
