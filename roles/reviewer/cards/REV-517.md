id: REV-517
rule: Do not let a change add a second copy of logic that already exists, and look for hidden copies too.
why: Beck's design rules, as Fowler lists them, say the code has no duplicated logic and warn about hidden duplication such as parallel class hierarchies.
applies-when: The PR adds logic that another file already holds, or a fixed list or limit that is typed in 2 or more places; the health step 14 search finds those copies.
not-when: The 2 copies look alike but carry different meaning, so a change to one never needs a change to the other.
example: In invented PR 101 for owner/shop, the check that a coupon is still valid is typed again in the export code. The reviewer names both copies with their file and line, and says the PR added the 2nd one.
