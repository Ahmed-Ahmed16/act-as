id: REV-201
rule: Read rules pages only from docs/business-rules/<area>.md on the default branch commit written down at the start. Never read one from the PR head, the working tree, a README or a wiki.
why: The spec fixes one place for the pages, so the PR cannot change the page it is judged against and the reviewer never has to guess where a rule lives.
applies-when: Looking for the rules page of a touched area.
not-when: A draft page is used for an area that has no page on the default branch (see REV-229 and REV-230).
example: In invented PR 101 for owner/shop, the order code changes. The reviewer reads docs/business-rules/ordering-and-cancelling.md from the default branch commit named in the identity line, not from the PR head.
mode: business, full
trigger: When looking for the rules page of an area
