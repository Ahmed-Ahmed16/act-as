id: REV-207
rule: If a rule line carries 2 statuses or none, do not read it. Write "not checked: rule <id> has <2 statuses or no status>" and make that area incomplete.
why: Ahmed settled in B15 that a rule with 2 statuses reads "multiple" and its area is incomplete. The page format gives each rule 1 status, so a rule with 2 would let the reviewer pick the status it likes.
applies-when: A rule line of a rules page has no status word, or more than 1.
not-when: none
example: In invented PR 101 for owner/shop, R4 reads "**match** **gap**". The reviewer writes "not checked: rule R4 has 2 statuses" and the area is incomplete.
mode: business, full
trigger: When a rule line has 2 statuses or none
kind: user-policy
source: user decision, reviewer v1 spec, amendment B15 (a rule with 2 statuses, Ahmed, 2026-10-27), which settles open question O6; and the approved business mode text (a rule with no status, settled 2026-10-27)
status: approved

The 4 status words (match, gap, owner, open) are this project's design.
