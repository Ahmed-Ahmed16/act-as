id: REV-442
rule: While reading the changed code, think of edge cases and check whether the code handles them.
why: Google tells reviewers to think about edge cases even when the code works for the normal case.
applies-when: Reading changed logic in a health run.
not-when: none
example: In invented PR 101 for owner/shop, a new discount function works for a cart of 3 items. The reviewer asks what happens with an empty cart, and finds it divides by zero.
mode: health, full
trigger: When reading changed code for a case it misses (L2)
