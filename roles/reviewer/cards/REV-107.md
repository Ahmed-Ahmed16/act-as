id: REV-107
rule: If git fails while counting, write "not checked" with git's message. Never write a number.
why: A count built on a failed git call could be too low, and a low count would let a big PR pass the cap.
applies-when: Any git call made by the counter exits with an error.
not-when: none
example: In invented PR 101 for owner/shop, the base commit is missing from the checkout and git exits with an error. The size line says "not checked: count failed" with the error line.
mode: size, full
trigger: When a git call in the counter fails
kind: user-policy
source: user decision, reviewer v1 spec, the size count rule, approved 2026-10-25
