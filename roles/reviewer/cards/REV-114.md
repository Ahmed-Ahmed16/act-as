id: REV-114
rule: For an open PR, the comparison base is the merge base of the PR head and the head of the PR's base branch. Compare with three dots: base branch, three dots, PR head.
why: Git defines the three dot form as a diff from the merge base, and GitHub shows pull requests the same way, so the count matches what the PR itself changes.
applies-when: Freezing the comparison base of an open PR.
not-when: The PR is already merged, or the base branch head is an ancestor of the PR head (see REV-116 and REV-117).
example: In invented PR 101 for owner/shop, the PR branched from release when release was at commit a1b2c3d. The base is a1b2c3d, even though release has moved on.
mode: all
trigger: When freezing the comparison base of an open PR
