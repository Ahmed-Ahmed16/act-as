id: REV-433
rule: Read the down() method of each new migration: it should reverse what up() does. A rollback undoes the last batch, which can hold several migration files.
why: Laravel says the down method should reverse the operations of the up method, and that rollback works on a batch that may include multiple migration files.
applies-when: A PR adds or changes a migration.
not-when: none
example: In invented PR 101 for owner/shop, the new migration has an empty down(). A rollback of its batch would leave the new column in place. The reviewer reports it.
mode: health, full
trigger: When reading the down method of a new migration
