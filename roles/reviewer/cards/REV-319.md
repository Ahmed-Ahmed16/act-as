id: REV-319
rule: A redirect target that comes from the request is accepted only if it is on a short list of allowed places, or if the server maps a short name or id to the full address.
why: OWASP says a redirect to a URL taken from user input lets an attacker build a safe looking link that sends the victim to another site. Do not let the destination URL be user input.
applies-when: A changed line redirects to a value from the request, such as redirect($request->next) or a return url.
not-when: The target is built by the app from a route name or a fixed path.
example: In invented PR 101 for owner/shop, after login the code runs redirect($request->input('next')). An attacker sends a link with next=https://evil.example and the login page sends the user there.
mode: security, full
trigger: When a changed redirect uses a request value
