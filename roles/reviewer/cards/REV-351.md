id: REV-351
rule: For a safeguard removed in the diff (authorize, can:, middleware, signed, throttle, validate, lockForUpdate, a where on user_id), ask 2 questions: was a reason given, and does something else guard the same thing now?
why: OWASP says a single missed permission check is enough for an attacker, so a removed guard is a place to look. The reviewer asks whether the removal was explained and whether another guard covers it.
applies-when: The diff removes a line that held one of these safeguards.
not-when: The removed line is moved to another place in the same change.
example: In invented PR 101 for owner/shop, the diff deletes ->middleware('throttle:5,1') from the login route and the PR text says nothing. The reviewer asks for the reason and looks for a limit that now sits elsewhere.
mode: security, full
trigger: When the diff removes a check or guard line
kind: source-advice
source: OWASP Authorization Cheat Sheet, Validate the Permissions on Every Request, https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html#validate-the-permissions-on-every-request, read 2026-10-27
