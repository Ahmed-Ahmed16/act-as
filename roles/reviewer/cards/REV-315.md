id: REV-315
rule: A route is left out of CSRF checks only if it is a server to server callback that checks a signature instead.
why: Laravel says to keep such routes outside the web middleware group. OWASP says to have the signature check in place before the CSRF exemption is granted.
applies-when: A change adds a URI to the CSRF except list, moves a route out of the web group, or adds a form with no CSRF field.
not-when: The route is a normal browser form that keeps its CSRF token.
example: In invented PR 101 for owner/shop, the PR adds 'payments/*' to the CSRF except list. The handler never checks a signature, so anyone can post a fake payment.
mode: security, full
trigger: When a route is excluded from CSRF protection
