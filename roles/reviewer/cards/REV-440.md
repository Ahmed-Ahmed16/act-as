id: REV-440
rule: When a Blade view changed, read the code that renders it as well. A view cannot be judged on its own.
why: Laravel says views are returned from routes or controllers, and that data is passed to the view by the code that returns it. So the data a view shows comes from that calling code.
applies-when: A changed Blade file in the PR.
not-when: none
example: In invented PR 101 for owner/shop, the PR changes invoice.blade.php to show $invoice->tax. The reviewer opens the controller that returns the view and finds it never passes tax. The reviewer reports it.
