id: REV-502
rule: Prefer the smallest change that solves the problem. Ask whether deleting code or reusing what exists would give the same result.
why: A third party review guide for coding agents tells them to lean toward deletion, and Beck's design rules, as Fowler lists them, end with the fewest possible classes and methods.
applies-when: The PR adds a new class, method, branch or file for something the code around it could already do with a smaller edit.
not-when: The smaller version is harder to read, or it drops a behaviour a test checks.
example: In invented PR 101 for owner/shop, the PR adds a new CartTotals class whose only method repeats the sum already in Cart::total(). The reviewer names Cart::total() as the smaller route.
