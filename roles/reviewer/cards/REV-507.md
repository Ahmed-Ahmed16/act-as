id: REV-507
rule: Check that each new name says in full what the thing is or does, and is not so long that it is hard to read.
why: Google defines a good name by that balance, and ties code that readers cannot understand quickly to too much complexity.
applies-when: The PR adds or renames a class, method, variable, route or config key.
not-when: none
example: In invented PR 101 for owner/shop, a new method is called handle() and it refunds a coupon. The reviewer writes the name as too vague and suggests refundCoupon().
