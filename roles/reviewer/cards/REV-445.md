id: REV-445
rule: A fixed list, or a single limit such as a size or a count, typed in 2 or more places should live in 1 place: a config entry, an enum or a language key. It counts as a copy only when both places express the same rule.
why: Beck's rule is that everything is said once. The catalog name for a bare number in code is a magic number, and the fix is a named constant. Two equal lists that mean different things are not copies.
applies-when: A changed hunk holds a fixed list or a limit.
not-when: none
example: In invented PR 101 for owner/shop, the PR types ['jpg','png','pdf'] in the upload request and again in the upload service. Both express the allowed upload types, so it is a copy. The home is config/uploads.php.
