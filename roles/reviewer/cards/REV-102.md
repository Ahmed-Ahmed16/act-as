id: REV-102
rule: Count a binary file as 0 lines. Git prints a dash in place of each count for a binary file, so read the dash as 0.
why: Git prints 2 dashes instead of 2 numbers for a binary file, so a counter that expects digits would crash or miscount on that line.
applies-when: A changed file is binary, such as an image or a font.
not-when: none
example: In invented PR 101 for owner/shop, logo.png changes. Git prints 2 dashes for it, and the counter adds 0 lines.
mode: size, full
trigger: When a changed file is binary
kind: source-advice
