id: REV-212
rule: When reading the code for a rule, also read the removed lines and the callers of the changed code. Do not stop at the files the Covers line names.
why: A rule can be broken by deleting a check or by a caller that skips one, and neither shows in the Covers files alone.
applies-when: Reading the base and head code for a rule.
not-when: none
example: In invented PR 101 for owner/shop, the diff removes a check in app/Support/Dates.php. The ordering page does not name that file, but its cancel code calls it, so the reviewer reads it.
mode: business, full
trigger: When reading the code behind a rule
