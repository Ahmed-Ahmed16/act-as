id: REV-123
rule: As a second check on the routes you found by reading, compare them with the output of php artisan route:list. Add -v to see each route's middleware.
why: Laravel says route:list gives an overview of all the routes the app defines. A route you read past, or one that a file you did not open adds, shows up there.
applies-when: The split step has listed the routes by reading and the role allows running the project's own code (full mode step 2, sub step b).
not-when: Running the project's code is not allowed or not possible in this run. Then write "not checked: route:list not run" and keep the list from reading.
example: In invented PR 101 for owner/shop, reading found 12 routes in routes/web.php. route:list shows 13, because a package adds one more. The reviewer names the extra route as read only from the list.
mode: full
trigger: When checking the routes found by reading against route:list
