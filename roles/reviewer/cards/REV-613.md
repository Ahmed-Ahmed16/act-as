id: REV-613
rule: User visible text in changed PHP and Blade should go through the translation helper. A literal that does not is a pointer, never must fix, and it never fails health.
why: Laravel's docs show text read from language files with the __ helper, and in Blade with the echo syntax. A literal skips the language files, so no other language can supply it.
applies-when: Reading changed PHP and Blade for text a user sees, such as a flash message, a button or a page title.
not-when: Text in logs, comments and tests.
example: In invented PR 101 for owner/shop, a Blade view has <button>Refund</button>. Check G4 lists the line. The reviewer opens it, sees a user visible word, and writes 1 pointer that it is not through __().
mode: health, full
trigger: When reading changed PHP and Blade for user visible text typed as a literal (G4)
