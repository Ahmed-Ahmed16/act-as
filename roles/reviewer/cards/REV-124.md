id: REV-124
rule: A console command is an entry point named by its $signature. Commands in app/Console/Commands load by themselves. routes/console.php holds closure commands. withCommands in bootstrap/app.php can add other folders or single command classes.
why: Laravel registers every command class in app/Console/Commands, treats the closure commands in routes/console.php as console entry points, and can scan more folders, or register single classes, when withCommands names them. So a command can live in any of those places.
applies-when: The split step lists the console commands of a Laravel project to find entry points (full mode step 2, sub step b).
not-when: none
example: In invented PR 101 for owner/shop, app/Console/Commands/SendReminders.php has the signature reminders:send, and routes/console.php has a closure command reports:weekly. Both are entry points. A changed helper that only SendReminders calls goes with reminders:send.
