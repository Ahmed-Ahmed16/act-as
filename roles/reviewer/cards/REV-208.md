id: REV-208
rule: When listing the changed files for the business step, turn rename detection on with git diff -M, so a renamed file shows as a rename.
why: The git manual says -M detects renames, and a configuration setting can turn detection off. Asking for -M on the command line keeps the list the same whatever the setting is.
applies-when: Running or reading the changed file list for the business step.
not-when: none
example: In invented PR 101 for owner/shop, app/Cart.php is renamed to app/Basket.php. With -M the list shows one rename. With rename detection off it shows a delete and an add.
mode: business, full
trigger: When listing the changed files for the business step
kind: source-advice
source: Git git diff documentation, option -M (--find-renames), https://git-scm.com/docs/git-diff#Documentation/git-diff.txt--Mn, read 2026-10-27
