id: REV-413
rule: List edited and deleted tests with git diff -M --name-status from the comparison base, so a moved test shows as a rename and not as a lost test.
why: -M makes git detect renames, and --name-status shows the status of each changed file. Together they separate a moved test from a deleted one.
applies-when: Running the tool part of check H7.
not-when: none
example: In invented PR 101 for owner/shop, tests/CartTest.php moves to tests/Feature/CartTest.php with no edits. git shows it as a rename, so the reviewer does not report a lost test.
mode: health, full
trigger: When listing old tests that were edited or deleted (H7)
kind: source-advice
