id: REV-308
rule: User input reaches SQL only as a bound value, written as ? or a name. It is never joined into the SQL string.
why: Laravel warns that raw expressions go into the query as plain strings, so you must be careful. OWASP says to use bindings for request data in raw queries.
applies-when: A changed line uses whereRaw, selectRaw, havingRaw, orderByRaw, DB::raw, DB::select or DB::statement.
not-when: The raw part holds no request data, or every request value is passed in the bindings array.
example: In invented PR 101 for owner/shop, the order search runs DB::select("select * from orders where ref = '" . $request->ref . "'"). A user sends a ref with a quote and a second statement, and the database runs it. The safe line is DB::select('select * from orders where ref = ?', [$request->ref]).
mode: security, full
trigger: When a changed query uses raw SQL
