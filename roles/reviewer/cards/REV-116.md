id: REV-116
rule: When the head of the PR's base branch is an ancestor of the PR head (a stacked part), that base branch head is the comparison base.
why: Git can test whether one commit is an ancestor of another. In a stack the PR targets the branch below it, so the lower branch head is where this PR starts.
applies-when: The base branch head is an ancestor of the PR head.
not-when: none
example: In invented PR 102 for owner/shop, part 2 targets the branch of part 1. Part 1's head is an ancestor of part 2's head, so part 1's head is the base.
mode: all
trigger: When the PR is a stacked part
