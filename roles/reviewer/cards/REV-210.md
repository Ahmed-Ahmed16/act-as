id: REV-210
rule: Put a changed file that no Covers line names in the no area found list. Give it a guessed area from the code you read, marked lead.
why: The list shows what is not mapped, and the label lead tells the reader that the guess is the reviewer's and not the page's.
applies-when: The page tool reports a changed file in no_area_found.
not-when: none
example: In invented PR 101 for owner/shop, config/orders.php is covered by no page. The reviewer writes "lead: config/orders.php, guessed area ordering, no page covers it" under Not checked.
mode: business, full
trigger: When a changed file is in the no area found list
