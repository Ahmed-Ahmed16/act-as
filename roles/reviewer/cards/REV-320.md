id: REV-320
rule: Keep secrets in the environment, not in code or in committed files. A fallback written inside env('KEY', 'value') is code, so a real key there counts as a leak.
why: Laravel says the .env file should not be in source control because it holds credentials. OWASP lists secrets written in source code in plain text as a common mistake.
applies-when: A change adds a key, token, password or connection string to a file in the repo, including config files and .env.example.
not-when: The value is a harmless test or placeholder value and the reviewer says so.
example: In invented PR 101 for owner/shop, config/services.php has 'secret' => env('PAY_SECRET', 'sk_live_abc123'). The fallback is a live key now sitting in the repo.
mode: security, full
trigger: When a change adds a key or token to a committed file
