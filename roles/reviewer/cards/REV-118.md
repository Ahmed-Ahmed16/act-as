id: REV-118
rule: Read the PR head as a full commit id once, at the start, and use that commit, not the branch name, for the whole run.
why: A branch name can move while the review runs, and the packet must name exactly what was read.
applies-when: Freezing the PR head before any mode runs.
not-when: none
example: In invented PR 101 for owner/shop, the head is frozen at its full commit id. The author pushes again mid review, and the review still reads the frozen commit.
mode: all
trigger: When freezing the PR head at the start
kind: user-policy
source: user decision, reviewer v1 spec, user story 15 and the run contract, approved 2026-10-25
