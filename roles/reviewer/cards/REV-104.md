id: REV-104
rule: Leave 4 kinds of file out of the counted lines: tests, lock files, generated files and docs. Migrations, language files, CI workflows and factories stay counted.
why: The user's size rule measures the hand written code a reviewer must read, so it leaves out these 4 kinds.
applies-when: The counter sorts each changed file into counted or left out.
not-when: none
example: In invented PR 101 for owner/shop, composer.lock changes by 400 lines and a migration by 40. Only the 40 lines are counted.
mode: size, full
trigger: When sorting changed files for the count
kind: user-policy
source: user decision, reviewer v1 spec, the size count rule, approved 2026-10-25
