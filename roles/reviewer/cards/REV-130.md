id: REV-130
rule: When 2 or more groups change the same file, list which hunks go to which group. Read the hunks with zero lines of context (git diff -U0).
why: With no context lines, git prints each changed spot as its own hunk. So each hunk can be placed in 1 group, and the lines of a shared file are not counted twice.
applies-when: A changed file is reached by more than 1 group, such as a routes file, a controller used by two routes, or a language file (full mode step 2, sub step e).
not-when: Only 1 group reaches the file. Then the whole file goes to that group.
example: In invented PR 101 for owner/shop, routes/web.php has 2 changed spots, one for the refund route and one for the export route. The plan puts hunk f1h1 in the refund group and f1h2 in the export group.
mode: full
trigger: When a changed file belongs to more than 1 group
