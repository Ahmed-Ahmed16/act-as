rule: If an area has a page on the default branch and also a draft, use the default branch page and add a pointer "Draft also exists, not used" with the draft path as reference.
why: An old draft must never override a page the owner signed.

not-when: none
example: In invented PR 101 for owner/shop, both docs/business-rules/ordering-and-cancelling.md and a draft of it exist. The reviewer uses the default branch page and writes the pointer.
mode: business, full
trigger: When an area has both a page and a draft
