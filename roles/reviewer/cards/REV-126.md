id: REV-126
rule: A Blade view is a screen. It is reached by something that shows it: a route or controller that returns it, Route::view, @include or @extends in another view, or a component under app/View/Components. A view that nothing shows is not an entry point.
why: Laravel returns Blade views from routes or controllers, includes and extends them from other views, and finds components in app/View/Components. Following those links tells you which entry point shows a changed view.
applies-when: The split step lists the screens of a Laravel project to find entry points (full mode step 2, sub step b).
not-when: none
example: In invented PR 101 for owner/shop, resources/views/refund/form.blade.php is returned by RefundController::create, so it belongs with the refund entry point. resources/views/partials/footer.blade.php is only @included by the layout, so it goes with the layout group.
