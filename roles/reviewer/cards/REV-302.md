id: REV-302
rule: Check that an action follows the project's own permission rules, including the exceptions the project allows, and not only that the user is logged in.
why: Laravel says a signed in user may still not be allowed to change a given record. It also shows a policy that lets administrators do any action, so "only the owner" is not true for every action.
applies-when: A changed action changes or shows data and the check in front of it only asks whether someone is logged in, or the project rule has an exception such as admin.
not-when: The project's written rules say the action is open to every signed in user.
example: In invented PR 101 for owner/shop, a refund button only needs a login. The project rule says only the order owner or an admin may refund. The reviewer asks where the owner check is and asks that the admin exception is written down.
mode: security, full
trigger: When a changed action is guarded only by a login check
