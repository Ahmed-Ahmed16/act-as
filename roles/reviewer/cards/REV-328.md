id: REV-328
rule: Debug mode is off in production. A change must not turn APP_DEBUG on for production, or hide it behind a default of true.
why: Laravel says the debug value should always be false in production, because true can show private configuration values to end users.
applies-when: A change touches the debug setting, config/app.php, an env default, or .env.example.
not-when: The value is for local development only and does not reach production.
example: In invented PR 101 for owner/shop, config/app.php now reads 'debug' => env('APP_DEBUG', true). A server with no APP_DEBUG variable shows full error pages with settings to every visitor.
mode: security, full
trigger: When a changed file sets the debug option
