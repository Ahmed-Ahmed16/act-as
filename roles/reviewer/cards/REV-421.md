id: REV-421
rule: A PHPStan run whose only issues are stale baseline entries ("ignored pattern was not matched") is clean. Report how many entries are stale.
why: PHPStan says that when an ignored error no longer occurs, the entry has to be removed from the baseline. That is a cleanup, not a bug in the code.
applies-when: The PHPStan output holds only lines about ignored patterns that were not matched.
not-when: none
example: In invented PR 101 for owner/shop, PHPStan prints 3 lines saying an ignored pattern was not matched and no other error. H9 is "clean", and the record says 3 stale baseline entries.
mode: health, full
trigger: When a PHPStan run reports stale baseline entries (H9)
kind: source-advice
source: PHPStan user guide, Baseline, https://phpstan.org/user-guide/baseline, read 2026-10-27
anchor: "you will have to remove the pattern from the baseline file"
