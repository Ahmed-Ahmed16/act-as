id: REV-408
rule: Treat each query call found in a changed controller as a candidate only. Open it and read whether the query or business rule belongs there. A hit you did not read is not a finding.
why: The spec wants every tool hit read before it counts, and a query in a controller is only worth a finding when the code shows the rule or query does not belong there.
applies-when: A grep for query calls (DB::, ::where(, ->join( and so on) hits a changed controller.
not-when: none
example: In invented PR 101 for owner/shop, the search hits ->where('active', 1) in InvoiceController. The reviewer opens it and sees a plain filter for a list page, so the result is "clean". A hit that holds a price rule is a finding.
mode: health, full
trigger: When searching changed controllers for query calls (H4)
