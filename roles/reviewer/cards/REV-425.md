id: REV-425
rule: Break the code that a picked test claims to guard, then run that test unchanged. If it stays green and the break really changed the behaviour, the test does not guard the behaviour it claims to guard: report must fix.
why: This is the idea of mutation testing: a change to the code that no test notices shows a gap in the tests. Infection calls such a change an escaped mutant.
applies-when: A test was picked for the independent check.
not-when: none
example: In invented PR 101 for owner/shop, the test says it guards the refund amount. The fault changes the amount by 1. The test is still green and the probe shows the amount changed, so the test does not guard the amount.
mode: health, full
trigger: When running the independent check on a picked test (H11)
kind: source-advice
source: Infection guide, What is Mutation Testing, https://infection.github.io/guide/#What-is-Mutation-Testing, read 2026-10-27
