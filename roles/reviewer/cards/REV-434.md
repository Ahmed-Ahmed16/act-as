id: REV-434
rule: Read what a new or changed migration does to the rows already in the table, and say what happens to them.
why: A migration that works on an empty test database can fail or lose data on a table that already has rows.
applies-when: A PR adds or changes a migration for a table that is in use.
not-when: none
example: In invented PR 101 for owner/shop, a migration adds a not null column with no default to a table that holds 40000 rows. The reviewer reports that it will fail on existing data unless a default or a fill step is added.
mode: health, full
trigger: When reading what a migration does to existing rows
