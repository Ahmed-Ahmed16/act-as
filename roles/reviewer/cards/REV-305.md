id: REV-305
rule: Pass a model only the request fields you picked or validated, never all the request input.
why: OWASP says to name the allowed fields with only() or validated() and not all(). Laravel says a user who sends an extra field such as is_admin can change a column you did not expect.
applies-when: A changed line passes request data to fill, create, update, updateOrCreate or a similar model method.
not-when: The array passed in is built by hand from named fields.
example: In invented PR 101 for owner/shop, the profile route calls $user->update($request->all()). A user adds is_admin=1 to the request and becomes an administrator.
mode: security, full
trigger: When request data goes into a model create or update
