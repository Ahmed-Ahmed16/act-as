id: REV-505
rule: Treat a new one off branch or special case put into an existing flow as a design problem, and prefer a dedicated helper or module for it.
why: A review guide for coding agents calls scattered special cases in unrelated flows a design problem, not a style point, and says to move the logic out instead of tangling the existing path.
applies-when: A pointer sent the reviewer here, and the PR adds an if or switch for 1 special case inside code that handles the common case.
not-when: none
example: In invented PR 101 for owner/shop, the PR adds `if ($user->id === 7)` inside the checkout total code. The reviewer asks for the case to live in a named helper or a rule the common path reads.
