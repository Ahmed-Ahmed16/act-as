id: REV-420
rule: A bug that the PR adds, once confirmed, is must fix, whichever tool found it. A bug that was already there is a lead.
why: The spec wants the same bug to get the same verdict, so the weight depends on who added it and not on which tool saw it.
applies-when: A confirmed bug is found by any tool or by reading.
not-when: none
example: In invented PR 101 for owner/shop, PHPStan and the reviewer both find a wrong variable in code the PR added. It is must fix. The same bug in a line the PR did not touch is a lead.
mode: health, full
trigger: When deciding the weight of a confirmed bug (H9)
