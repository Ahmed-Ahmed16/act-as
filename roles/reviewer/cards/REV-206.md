id: REV-206
rule: Treat the status on a rules page (match, gap, owner, open) as a hint. Read the code each rule is about again, at the comparison base and at the PR head.
why: The page says only what was true at the commit named in its Checked at line. A stale label could hide a change that broke the rule, so the code decides.
applies-when: Judging a rule of a touched area.
not-when: none
example: In invented PR 101 for owner/shop, R3 is marked match. The reviewer still reads the cancel code at the base and at the PR head before saying R3 holds.
mode: business, full
trigger: When reading the code for a rule
