id: REV-446
rule: To find other copies, search the repo for the same literal text with a fixed string search, and also for the config key or language key that holds it. Name every other copy as path:line.
why: A fixed string search looks for the exact text and not for a pattern, so it finds copies that a regular expression would miss or confuse.
applies-when: Running the search step for a fixed list or a limit in a changed hunk.
not-when: none
example: In invented PR 101 for owner/shop, a search for the text 2048 finds it in the upload request and in config/uploads.php. The reviewer names both as path:line and reads whether they mean the same limit.
mode: health, full
trigger: When searching for the other copies of a list or limit (G2)
