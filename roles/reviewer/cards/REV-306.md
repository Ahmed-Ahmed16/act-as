id: REV-306
rule: Do not set $guarded to an empty array, and do not use forceFill or forceCreate on request data. They switch off the model's protection.
why: OWASP says an empty guarded array and the force methods turn off Laravel's built in mass assignment protection. Laravel allows an empty array only if you always hand craft what you pass in.
applies-when: A changed model sets $guarded = [], or code calls forceFill or forceCreate.
not-when: The values passed to forceFill are a validated array built by hand.
example: In invented PR 101 for owner/shop, the Order model gets protected $guarded = []. Any column, including status and paid_at, can now be set from request data.
mode: security, full
trigger: When a model is unguarded or force methods are used
