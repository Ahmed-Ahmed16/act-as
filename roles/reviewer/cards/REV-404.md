id: REV-404
rule: A method that PHPMD's ExcessiveMethodLength flags is a pointer with 1 line of judgement. It is never a finding by itself.
why: PHPMD says a long method usually means the method does too much. "Usually" is why a person must read it: a plain list of menu entries can be long and fine.
applies-when: PHPMD reports ExcessiveMethodLength on a changed PHP file.
not-when: none
example: In invented PR 101 for owner/shop, PHPMD flags a 120 line method. The reviewer reads it. The pointer says "120 line method: fine, a plain list of menu entries".
mode: health, full
trigger: When PHPMD flags a long method (H2)
kind: source-advice
source: PHPMD rules, Code Size Rules, ExcessiveMethodLength, https://phpmd.org/rules/codesize.html#excessivemethodlength, read 2026-10-27
