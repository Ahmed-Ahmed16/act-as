id: REV-354
rule: A step that may run only once must fail when it is sent again. Mark the step done in saved data, and treat a repeat as an error.
why: OWASP says that once a step is completed, later attempts to run it should fail, above all for single use operations such as a coupon or a bonus.
applies-when: A change adds or edits a step that should happen once, such as redeeming a coupon, confirming a payment or claiming a reward.
not-when: The step can safely run many times and gives the same result each time.
example: In invented PR 101 for owner/shop, the redeem endpoint adds 10 credit each time it is called. A user presses the button twice and gets 20.
mode: security, full
trigger: When a change adds a step that should happen once
kind: source-advice
