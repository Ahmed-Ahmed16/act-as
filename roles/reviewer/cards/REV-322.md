id: REV-322
rule: Write down what the signed link is meant to allow, then decide if it needs an expiry. A link that should not work for ever uses a temporary signed route.
why: Laravel offers a temporary signed route that expires after a set time, and checks that the time has not passed. Whether a link needs it depends on what the link does.
applies-when: A changed line creates a signed link, or the expiry on one is added or removed.
not-when: The link is meant to work for ever, such as a public unsubscribe link, and the intended access rule says so.
example: In invented PR 101 for owner/shop, a signed link opens an invoice download and uses signedRoute with no expiry. The link works for ever, so the email stays a key to the invoice. temporarySignedRoute with 30 minutes fits the purpose.
mode: security, full
trigger: When a changed signed link has or lacks an expiry
