id: REV-350
rule: Read every version downgrade in the manifest or lock diff. Say why a package went back to an older version.
why: The spec lists a downgrade next to a new package, a new repositories entry and a new scripts entry as a change to read. An older version can bring back a fixed vulnerability.
applies-when: A PR lowers the version of a package in composer.json or composer.lock.
not-when: The PR does not lower a version.
example: In invented PR 101 for owner/shop, the lock diff moves a framework package from 11.9 to 11.2. The reviewer asks why, and checks whether 11.2 has an advisory that 11.9 fixed.
mode: security, full
trigger: When a PR lowers a package version
