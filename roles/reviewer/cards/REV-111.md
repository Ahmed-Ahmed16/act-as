id: REV-111
rule: Name any changed file that has no link to the task the PR states. It is a lead, and it only changes the reading order: read it first.
why: The spec's L5 check treats a file with no reason in the task as a lead that sets the reading order only. Google wants a change to address just one thing, so a file that serves another purpose stands out.
applies-when: The list of changed files holds a file the PR's stated task does not explain.
not-when: none
example: In invented PR 101 for owner/shop, the task is a cart discount, but resources/lang/fr/emails.php also changes. The reviewer names that file as a lead and reads it first.
mode: size, full
trigger: When reading the list of changed files
