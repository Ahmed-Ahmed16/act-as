id: REV-348
rule: A new scripts entry in composer.json runs a command on every machine that runs Composer. Read it like code.
why: Composer says a script can be any command line command, and that scripts defined in the root package are run during Composer's work.
applies-when: A PR adds or changes a scripts entry in composer.json.
not-when: The entry only runs a documented tool such as the test runner, and the reviewer has read the command.
example: In invented PR 101 for owner/shop, the PR adds a post install script that downloads and runs a file from a web address. Every developer and the deploy server run it on the next install.
mode: security, full
trigger: When a PR adds a Composer script
kind: source-advice
source: Composer docs, Scripts, What is a script, https://getcomposer.org/doc/articles/scripts.md#what-is-a-script, read 2026-10-27
anchor: "any command-line executable command"
