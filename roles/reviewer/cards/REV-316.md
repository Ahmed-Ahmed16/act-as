id: REV-316
rule: Print user text with escaped output. Raw output ({!! !!}) is allowed only when no user of any role can write that text.
why: Laravel says to be very careful when echoing user supplied content and to use the escaped double curly brace form. OWASP says the raw form must not be used on untrusted data.
applies-when: A changed Blade view uses {!! !!} or builds HTML from stored text.
not-when: The value is HTML the app itself builds, and no user input reaches it.
example: In invented PR 101 for owner/shop, the comment view prints {!! $comment->body !!}. A user posts a script tag as a comment, and it runs for every reader. The fix is {{ $comment->body }}.
mode: security, full
trigger: When a changed view prints data without escaping
