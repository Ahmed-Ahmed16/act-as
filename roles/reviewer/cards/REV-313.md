id: REV-313
rule: Allow only the file types the feature needs, and treat SVG as a file that can carry script. Check what the project's Laravel version lets the image rule accept.
why: Laravel 12 says the image rule leaves out SVG by default because SVG can carry script, and image:allow_svg lets it in. OWASP says to allow only the types the business needs.
applies-when: A changed validation accepts an uploaded file, above all with the image or mimes rule.
not-when: The feature has to accept SVG, the file is cleaned first, and it is never served to a browser from your own site.
example: In invented PR 101 for owner/shop, the logo upload uses 'logo' => 'image' and stores the file on the public disk. On Laravel 11 an SVG with a script inside passes. When a user opens the file's address in the browser, the script runs on the site's own domain. The same SVG shown only through an img tag does not run its script.
mode: security, full
trigger: When a changed validation decides which upload types are allowed
kind: source-advice
source: Laravel 12.x docs, Validation, rule image, https://laravel.com/docs/12.x/validation#rule-image, read 2026-10-27 ; second source: OWASP File Upload Cheat Sheet, List Allowed Extensions, https://cheatsheetseries.owasp.org/cheatsheets/File_Upload_Cheat_Sheet.html#list-allowed-extensions, read 2026-10-27
anchor: "does not allow SVG files due to the possibility of XSS"
