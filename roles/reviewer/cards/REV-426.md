id: REV-426
rule: The picked test must go red on an assertion failure. A red from a fatal error or a parse error is "not checked: red was not an assertion failure".
why: PHPUnit marks an assertion failure with F. A different mark is used for an error, so a red that is not an F does not show the test noticed the fault.
applies-when: The picked test ran with the fault in place and failed.
not-when: none
example: In invented PR 101 for owner/shop, the test fails with a fatal error because the fault broke a class name. That red is not an assertion failure. The result is "not checked: red was not an assertion failure".
mode: health, full
trigger: When the picked test goes red under the fault (H11)
kind: source-advice
source: PHPUnit 12.5 documentation, The Command Line Test Runner, Progress, https://docs.phpunit.de/en/12.5/textui.html#progress, read 2026-10-27
