id: REV-223
rule: If the PR changes a rule on a rules page, show the change on its own line: "PR changes rule <id> on the page; needs the owner's yes".
why: The owner has not said yes to a rule the PR rewrites, so the reader must see the change as its own line and not take the new page text as settled.
applies-when: The PR diff changes a rule line on a rules page.
not-when: none
example: In invented PR 101 for owner/shop, the PR edits R3 on the page. The packet adds the line "PR changes rule R3 on the page; needs the owner's yes".
mode: business, full
trigger: When the PR changes a rule on a rules page
