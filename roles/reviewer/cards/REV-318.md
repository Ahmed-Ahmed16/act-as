id: REV-318
rule: A spreadsheet or CSV export must not let a cell start with =, +, - or @ from user text. Treat such a cell so the spreadsheet reads it as text.
why: OWASP says a cell starting with = is run as a formula when someone opens the file in a spreadsheet program. The attacker can steal data or take over the computer.
applies-when: A changed export writes user entered text into CSV or an Excel file (fputcsv, an export class).
not-when: The export holds only numbers and text the app makes, no user text.
example: In invented PR 101 for owner/shop, the orders export writes the customer's note into a CSV cell. A customer wrote =HYPERLINK("http://evil.example","x") as the note, and it runs in the accountant's spreadsheet.
mode: security, full
trigger: When a changed export writes user text into a spreadsheet cell
kind: source-advice
source: OWASP Community, CSV Injection, https://owasp.org/www-community/attacks/CSV_Injection, read 2026-10-27
anchor: "ensure that no cells begin with any of the following characters"
