id: REV-309
rule: User input never picks a column name in a query, including the order by column. Check it against a fixed list first.
why: Laravel says the database cannot bind column names, so user input must never decide them. OWASP shows a sort column from the request and fixes it with an in: list.
applies-when: A changed line passes request data to orderBy, where, select or another call as a column name.
not-when: The column name comes from a fixed list in the code.
example: In invented PR 101 for owner/shop, the product list runs orderBy($request->order). A user sorts by cost_price, a private column, and learns the order of the costs. The fix compares the value with a fixed array of 3 sortable columns and falls back to created_at.
mode: security, full
trigger: When request data is used as a column name
