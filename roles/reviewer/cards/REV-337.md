id: REV-337
rule: When the server fetches a URL given by a user, use a list of allowed hosts whenever possible. If the feature must fetch any external address, a list cannot work, so block internal and private addresses instead.
why: OWASP says to use allow lists of origins, schemes and ports whenever possible. Where a feature must reach any external address, the SSRF sheet says an allow list does not fit and a block list of internal ranges is the way.
applies-when: A changed line fetches a URL, host or IP from request data (Http::get, file_get_contents, curl).
not-when: The URL is built from a fixed host and only a path part comes from the user.
example: In invented PR 101 for owner/shop, the avatar importer runs Http::get($request->url). A user sends http://169.254.169.254/ and the server returns the cloud machine's private data.
mode: security, full
trigger: When a changed line fetches a URL from request data
