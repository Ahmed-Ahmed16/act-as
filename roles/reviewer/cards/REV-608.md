id: REV-608
rule: A value with no letters of its language is a pointer. Arabic needs Arabic script letters and English needs Latin letters. Skip a value made only of placeholders, numbers or symbols. A language with no entry is "not checked", never a pass.
why: An English word left in the Arabic file, such as "Save", shows English to an Arabic reader and no check sees it. Unicode script data says which letters belong to which script, and digits and symbols carry no script of their own.
applies-when: Running check T8 on a language file value.
not-when: The value holds only placeholders such as :count, digits, or symbols such as %.
example: In invented PR 101 for owner/shop, lang/ar.json maps "Save" to "Save". Check 8 lists it, because the value has no Arabic letters. A value ":count" in the same file is skipped.
mode: health, full
trigger: When running translation check T8 (a value with no letters of its language)

extra: The data file (version 18.0.0, dated 2026-06-29) puts Arabic letters in several ranges, this being the first; capital Latin letters are 0041..005A and digits are Common (0030..0039). Common characters, such as the Arabic comma, take their script from the text around them (UAX 24), so a value of only punctuation is skipped. The rule, the language list (ar, en) and the pointer status are spec B11.
