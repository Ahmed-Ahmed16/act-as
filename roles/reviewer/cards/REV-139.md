id: REV-139
rule: Read the on: block of every workflow file at the frozen head and record it as written. Note the branch and path filters. If a file cannot be read, say unreadable. Do not guess what its filters do.
why: GitHub runs a workflow only when its filters match, and a branch filter plus a path filter must both match. A guess about the filters can hide that a part gets no CI.
applies-when: The split step records the CI trigger of the repo (full mode step 2, sub step i).
not-when: none
example: In invented PR 101 for owner/shop, ci.yml has on: pull_request: branches: [main] and paths-ignore: [docs/**]. The reviewer records that text. A part that changes only docs/ gets no run from this file.
mode: full
trigger: When reading the CI workflow files for the split plan
