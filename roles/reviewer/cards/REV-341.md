id: REV-341
rule: Check who can read the log files and where they are sent. Logs hold personal data and technical secrets, so reading them needs the same care as the data.
why: OWASP says to decide who may read which logs, because logs hold personal data and technical secrets like passwords, and a reader who should not see them can use them for deeper attacks.
applies-when: A change adds a log channel, a log destination, a log viewer or a new kind of logged data.
not-when: The change only adds a log line of harmless data to an existing channel.
example: In invented PR 101 for owner/shop, the PR sends the application log to a shared chat channel. Everyone in the channel can now read the user emails that the log holds.
mode: security, full
trigger: When a change adds a log destination or a log reader
kind: source-advice
source: OWASP Logging Cheat Sheet, Confidentiality, https://cheatsheetseries.owasp.org/cheatsheets/Logging_Cheat_Sheet.html#confidentiality, read 2026-10-27
