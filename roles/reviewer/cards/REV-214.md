id: REV-214
rule: If a rule marked match is broken by the PR, in old or new code, make it a must fix finding and make the area fail.
why: The rules page says what the business wants. The question is whether the PR still does that, not only what the code did before.
applies-when: A rule marked match is broken at the PR head.
not-when: none
example: In invented PR 101 for owner/shop, R3 (match) says an order can be cancelled within 24 hours. With the PR it can be cancelled within 12 hours. That is a must fix finding and the area fails.
mode: business, full
trigger: When a match rule is broken by the PR
