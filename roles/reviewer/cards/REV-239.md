id: REV-239
rule: A rerun recomputes the SHA 256 of every draft page and glossary it uses. When one differs from the first run, it writes "page changed since the first run: <area>".
why: A draft edited between the first run and the rerun would change what the rerun reads. The line shows it, so the reader knows the two runs did not read the same text.
applies-when: A business rerun uses a draft page, or a glossary file a page points to.
not-when: none
example: In invented PR 101 for owner/shop, gifts.md was edited after the first run. The rerun hashes it again, sees a different SHA 256, and writes "page changed since the first run: gifts".
mode: business
trigger: When a business rerun checks draft pages
