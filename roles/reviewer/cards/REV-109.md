id: REV-109
rule: A PR over the cap goes back to the author with a request to split it into smaller changes that build on each other.
why: Google tells a reviewer to ask the author to split a change that is too large to read well, instead of reading it in one go.
applies-when: The counted lines are 301 or more.
not-when: The user said "review it anyway" for this run.
example: In invented PR 101 for owner/shop, 640 counted lines stop the run, and the draft message asks the author to split the work into smaller PRs.
mode: size, full
trigger: When a PR is over the 300 line cap
