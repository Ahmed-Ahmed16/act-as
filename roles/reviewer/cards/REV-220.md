id: REV-220
rule: If the PR changes behaviour under a rule marked owner or open, make the area incomplete and write "depends on: owner answers <id>".
why: An owner or open rule has no settled answer yet. Nobody should merge past an open question as if it were closed.
applies-when: A rule marked owner or open, and the PR changes behaviour under it.
not-when: none
example: In invented PR 101 for owner/shop, R4 (open) asks how long gift cards last, and the PR changes that period. The area is incomplete with "depends on: owner answers R4".
mode: business, full
trigger: When the PR changes behaviour under an owner or open rule
