id: REV-129
rule: Each part carries the tests for its own code. A test goes in the same part as the code it tests.
why: Google says a change should include its related test code. A part with the code but not its tests, or tests for code in another part, cannot be read or run on its own.
applies-when: The split step places the changed test files and test hunks into groups and parts (full mode step 2, sub step e).
not-when: The test checks code that the PR did not change. Link it to that unchanged file at the frozen head and record the command used to check the file.
example: In invented PR 101 for owner/shop, RefundTest.php tests RefundService, which the refund group adds. The test goes in the refund group, not in a group of tests.
mode: full
trigger: When placing a changed test into a group or part
