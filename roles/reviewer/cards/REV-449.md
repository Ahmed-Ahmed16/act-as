id: REV-449
rule: Every number from a tool or a guard is a pointer. Give each pointer 1 line of judgement and a review question number. A pointer never passes or fails health.
why: Numbers like 100 lines or 10 routes are a reason to look, not a verdict. A person must judge whether the code is a problem.
applies-when: A tool or a guard skill gives a number (a line count of a method, class or changed file, a route count, a complexity score, a clone count).
not-when: none
example: In invented PR 101 for owner/shop, a guard reports a method at complexity 12. The pointer says "complexity 12: fine, a flat switch over 12 statuses". An unnamed guard finding that is not a number stays a finding.
mode: health, full
trigger: When a tool or a guard gives a number
