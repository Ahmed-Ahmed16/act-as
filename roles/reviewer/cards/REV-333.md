id: REV-333
rule: Read the default value of every env() call that a change adds or edits. The default is what production runs with when the variable is missing, so it must be a safe value.
why: The spec asks the reviewer to read the default of an env() call. Laravel's own config shows the pattern: env('APP_DEBUG', false), a safe default.
applies-when: A change adds or edits an env() call in a config file.
not-when: The default is a debug flag (REV-328), a secret (REV-320) or a cookie option (REV-329 to REV-331), which have their own cards. Or the default is empty and the code fails closed.
example: In invented PR 101 for owner/shop, config/admin.php reads 'allowed_ips' => env('ADMIN_ALLOWED_IPS', '*'). A server with no such variable lets every address reach the admin area.
mode: security, full
trigger: When a changed config file calls env with a default
