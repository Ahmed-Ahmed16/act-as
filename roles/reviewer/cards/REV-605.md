id: REV-605
rule: List the old keys whose value the PR changed, apart from everything else and first, in "Translations by page", before any group. It is a pointer: never a finding, never must fix, never fails health. Give it 1 line of judgement and the reference translation check 5.
why: The spec wants changed old text shown apart from new keys, so a reader sees what was reworded before reading the new keys.
applies-when: Running check T5 on a PR that edits an existing value of a key that exists on the comparison base.
not-when: The key is new in the PR. An edited English text used as the key is a new key, not a changed value (see REV-610).
example: In invented PR 101 for owner/shop, the PR changes the ar value of the PHP key orders.shipped. Check 5 lists the old and new value. The reviewer writes 1 pointer line: "wording change, same meaning, fine".
mode: health, full
trigger: When running translation check T5 (changed old values)
