id: REV-334
rule: User input never reaches a shell command string. Avoid the shell; if a process is needed, fix the program name and pass the arguments one by one.
why: OWASP says the main defence is to not call OS commands directly. If a process is needed, keep the executable fixed and pass arguments as an array.
applies-when: A changed line calls exec, shell_exec, system, passthru, proc_open, backticks or Process::run.
not-when: The whole command is fixed text and no request value reaches it.
example: In invented PR 101 for owner/shop, the backup button runs shell_exec('tar -czf backup.tgz ' . $request->folder). A user sends a folder name followed by a semicolon and a second command, and the server runs both.
mode: security, full
trigger: When a changed line runs a shell command
