id: REV-438
rule: For a changed job, read how many attempts it gets, what each retry repeats, and whether running it twice would do harm.
why: Laravel lets you set the maximum number of attempts for a job. After that many attempts the job goes to the failed jobs table. Every attempt before that runs the job again.
applies-when: A PR changes a job class or its attempt settings.
not-when: none
example: In invented PR 101 for owner/shop, a job charges a card and then sends an email, and it can be tried 3 times. If the email step fails, the retry charges again. The reviewer reports it.
mode: health, full
trigger: When a changed job can be retried
