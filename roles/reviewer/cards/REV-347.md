id: REV-347
rule: A new repositories entry in composer.json needs reading and a reason. A custom repository has priority over the default package source.
why: Composer says a package from a custom repository is picked over the original from Packagist. OWASP says to get components only from official sources.
applies-when: A PR adds or changes a repositories entry in composer.json.
not-when: The entry points to the project's own private package host, named in the project's rules.
example: In invented PR 101 for owner/shop, the PR adds a vcs repository for a fork of a logging package. The fork now replaces the real package, so whoever controls the fork controls the code the app runs.
mode: security, full
trigger: When a PR adds a Composer repository entry
kind: source-advice
