id: REV-101
rule: Count each changed file as its added lines plus its deleted lines, read from git for the frozen comparison.
why: Git's numstat option prints the added and deleted line counts for every path, so the counter has 1 place to read them from.
applies-when: Every time the counter measures a PR against the 300 line cap.
not-when: none
example: In invented PR 101 for owner/shop, a file with 12 lines added and 5 lines deleted counts as 17 lines.
mode: size, full
trigger: When counting changed lines
kind: source-advice
source: Git - git-diff Documentation, --numstat, https://git-scm.com/docs/git-diff#Documentation/git-diff.txt---numstat, read 2026-10-26
anchor: "shows number of added and deleted lines in decimal notation"
