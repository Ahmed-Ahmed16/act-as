rule: Ask whether a unit test for the changed code could be pointed at that small part alone, without loading most of the system.
why: This project asks it so that a rule can be tested without starting most of the system. Fowler describes unit tests as focused on a small part of the system, which is the idea behind the question.
applies-when: The PR adds or changes a class or method that has logic, and a test for it would need most of the system loaded, such as the whole app and many other classes.
not-when: The test uses real collaborators that are stable and fast, a database included; Fowler accepts these sociable tests. Or the code is glue with no rule of its own, such as a service provider.
example: In invented PR 101 for owner/shop, the new discount rule can only be tested by booting the whole app with every service provider. The reviewer writes that no unit test can reach it alone, and names the class.
