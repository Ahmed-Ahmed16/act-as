id: REV-521
rule: Ask whether the tests would fail if the code were broken. Tests do not test themselves, so a person must check this.
why: Google asks this question about every test in a PR, and mutation testing treats a test that stays green on altered code as a missed fault.
applies-when: The PR adds or changes a test for changed code.
not-when: none
example: In invented PR 101 for owner/shop, a new test calls the refund method and only asserts that no exception was thrown. The reviewer writes that it would stay green if the refund amount were wrong.
