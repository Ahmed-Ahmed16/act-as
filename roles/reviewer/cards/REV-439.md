id: REV-439
rule: When a PR changes a job or listener, check that queue workers are restarted on deploy.
why: Laravel says queue workers are long lived processes and do not notice code changes until they are restarted.
applies-when: A PR changes the class of a queued job or listener.
not-when: none
example: In invented PR 101 for owner/shop, the PR changes how SendInvoice builds the email. The deploy script does not restart the queue workers, so they keep running the old code. The reviewer reports it.
mode: health, full
trigger: When a PR changes a job or a listener class
