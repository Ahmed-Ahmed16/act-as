id: REV-419
rule: Open every PHPStan error and confirm it by reading the code. An error you did not confirm is not a finding.
why: The spec wants every tool hit read before it counts, so a tool alone never makes a finding.
applies-when: PHPStan reports one or more errors.
not-when: none
example: In invented PR 101 for owner/shop, PHPStan reports a possibly null value at line 52. The reviewer reads the code and sees the value is checked 3 lines up, so the error is not a bug.
mode: health, full
trigger: When PHPStan reports an error (H9)
