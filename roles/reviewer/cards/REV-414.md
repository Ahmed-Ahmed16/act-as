id: REV-414
rule: Judge each deleted or changed test by lost protection: would it still fail if the code broke? A reason written in the PR text does not count. A lost protection confirmed in the code is must fix.
why: Google's question for a reviewer is whether the tests will fail when the code is broken. A deleted test cannot fail, whatever the author says.
applies-when: A test was deleted, or a changed test has weaker assertions than before.
not-when: none
example: In invented PR 101 for owner/shop, the PR deletes a test that checks a coupon cannot be used twice, and says "covered elsewhere". The reviewer searches, finds no other test, and reports must fix: lost protection.
mode: health, full
trigger: When judging a deleted or changed test (H7)
