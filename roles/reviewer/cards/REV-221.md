id: REV-221
rule: If the PR changes a rule on the page and the code under it together, make the area incomplete and write "merge only after: owner says yes to the <id> change".
why: The code now matches the new page, but only the owner can say the new rule is wanted. The reviewer must not treat the PR's own page change as approval.
applies-when: The PR changes a rules page and the code for the same rule.
not-when: none
example: In invented PR 101 for owner/shop, the PR changes R9 on the page from 24 to 12 hours and changes the code the same way. The area is incomplete: "merge only after: owner says yes to the R9 change".
mode: business, full
trigger: When a rule and its code are changed in the same PR
