id: REV-211
rule: Judge a lead whose file changes behaviour by its guessed area. If that area has no page, write "not checked: no rules page for <area>, grill needed".
why: A config change can move a business rule. If leads were skipped, that change would slip by with no page to check it against.
applies-when: A lead file changes behaviour, not only comments or formatting.
not-when: none
example: In invented PR 101 for owner/shop, config/orders.php changes the cancel window from 24 to 12. The guessed area is ordering, so the ordering page judges it. If there is no ordering page, the reviewer writes the grill needed line.
mode: business, full
trigger: When a lead file changes behaviour
