id: REV-216
rule: If a rule marked gap is made worse by the PR (a check removed or weakened, a wider reach, or a new door that copies the weakness), make it a must fix finding and make the area fail. This row comes before the other gap rows.
why: The old hole was already there, so only new damage fails. A new door that copies the hole is new damage.
applies-when: A rule marked gap is made worse at the PR head.
not-when: none
example: In invented PR 101 for owner/shop, R10 (gap) says a cancel needs a login, but the old cancel route does not check it yet. The PR adds a new cancel route that also skips the login check. A new door copies the weakness, so it is a must fix finding and the area fails.
mode: business, full
trigger: When a gap rule is made worse by the PR
