id: REV-103
rule: Count a renamed or moved file the way GitHub counts it. A pure move counts 0 lines. A move with edits counts only its changed lines.
why: The user chose to follow GitHub, so a file that only changed its path does not add to the cap, and only the lines that really changed count.
applies-when: A changed file was moved or renamed.
not-when: none
example: In invented PR 101 for owner/shop, app/Cart.php (90 lines) becomes app/Basket.php with no edit. It counts 0 lines. If 4 lines were also edited, it counts those 4 lines.
mode: size, full
trigger: When a changed file was renamed
