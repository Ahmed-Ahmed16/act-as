id: REV-410
rule: A test found by name or route is only a candidate. Trace the call and read its assertion before you write "covered".
why: Google tells reviewers to ask whether a test would really fail when the code is broken. A test with the right name can still assert nothing useful.
applies-when: A search by name, route or caller turns up a test for a risky area.
not-when: none
example: In invented PR 101 for owner/shop, CheckoutTest has a test named test_refund. The reviewer opens it and finds it only asserts a 200 status, not the amount. The area is not "covered".
mode: health, full
trigger: When a test is found for a risky area (H6)
