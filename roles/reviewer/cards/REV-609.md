id: REV-609
rule: With English text as the key, a key missing from the Arabic file shows the English text with no error. State this as a fact when a missing key is reported.
why: Laravel returns the key it was given when it finds no translation. With English text as the key, the key is the English text.
applies-when: Reporting a missing key (T1 or T2) in a project whose keys are English text in JSON files.
not-when: The project uses short keys in PHP files. A missing short key shows the key itself, such as orders.title.
example: In invented PR 101 for owner/shop, "Order shipped" is in en.json and not in ar.json. An Arabic reader sees "Order shipped" in English. No error is logged. The reviewer states that fact next to the finding.
mode: health, full
trigger: When reporting a missing key in a project that uses English text as keys
