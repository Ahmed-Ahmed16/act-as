id: REV-417
rule: When reading changed code, look for code that no caller uses and for wrappers that have only 1 caller.
why: Step 4 of one author's refactoring playbook is to subtract before you add: delete dead code and collapse wrappers with 1 caller. A reviewer can look for the same things in a diff.
applies-when: Reading the changed code in check H8, after the tools ran.
not-when: none
example: In invented PR 101 for owner/shop, the PR adds ReportHelper::run(), a method that only calls ReportService::run(). Its only caller is 1 controller. The reviewer reports it as a wrapper to collapse.
