id: REV-335
rule: User input never reaches unserialize, eval or extract.
why: OWASP says to avoid passing untrusted input to these functions. The PHP manual warns that unserialize can load and run code, and recommends JSON for data that passes through users.
applies-when: A changed line calls unserialize, eval or extract.
not-when: The data is written and read by the app only, and no user can change it.
example: In invented PR 101 for owner/shop, the import runs unserialize($request->input('data')). A crafted string builds an object that runs code when the app loads it.
mode: security, full
trigger: When a changed line calls unserialize, eval or extract
kind: source-advice
