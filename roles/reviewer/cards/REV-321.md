id: REV-321
rule: A route that depends on a signed link must run the signature check, with the signed middleware or hasValidSignature. A link that was signed when sent does not protect a route that never checks it.
why: Laravel says signed URLs protect public routes against URL changes, and that the signed middleware gives a 403 when the signature is not valid. A route without the check accepts any link.
applies-when: A changed route is reached by a signed link, or the signed middleware or a hasValidSignature check is added or removed.
not-when: The route is not meant to be reached by a signed link.
example: In invented PR 101 for owner/shop, the unsubscribe email carries a signed link, but the route has no signed middleware. A user changes the user id in the link and unsubscribes someone else.
mode: security, full
trigger: When a changed route is reached by a signed link
