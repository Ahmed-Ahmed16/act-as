id: REV-110
rule: When it is unclear what a change is meant to do, you may read its tests before the main code. Do not make that a fixed order.
why: Google says reading the tests first is sometimes helpful, and it does not say the tests must come first.
applies-when: Choosing in what order to read the files of a PR.
not-when: none
example: In invented PR 101 for owner/shop, the description is thin, so the reviewer reads tests/CartTest.php first to see what the change should do.
