id: REV-338
rule: The HTTP client that fetches a user URL does not follow redirects.
why: OWASP says to switch off redirect following in the web client, because a redirect can send the request to a host that the allow list would have refused.
applies-when: A changed line fetches a URL from request data with an HTTP client.
not-when: The URL is not user supplied.
example: In invented PR 101 for owner/shop, the importer allows only images.example, but the client follows redirects. A page on that host redirects to an internal address and the server fetches it.
mode: security, full
trigger: When a changed HTTP client call fetches a user URL
kind: source-advice
