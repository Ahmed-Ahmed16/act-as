id: REV-443
rule: Read for behaviour that worked before the PR and no longer does.
why: A refactor is meant to change the structure and keep the observable behaviour. Behaviour that stops working is a regression, whatever the PR is called.
applies-when: Reading changed logic in a health run, above all in a PR called a refactor or cleanup.
not-when: none
example: In invented PR 101 for owner/shop, the PR "cleans up" the coupon check and now accepts expired coupons. The reviewer reports that the old behaviour (reject expired) no longer holds.
mode: health, full
trigger: When reading changed code for behaviour that worked before (L3)
kind: source-advice
source: Martin Fowler, DefinitionOfRefactoring, https://martinfowler.com/bliki/DefinitionOfRefactoring.html, read 2026-10-27
anchor: "without changing its observable behavior"
