id: REV-523
rule: When a PR changes how people build, test, use or release the code, or adds behaviour that no document mentions, check that the docs were updated or added. If a doc is missing, ask for it.
why: Google tells reviewers to check that such a change also updates the docs, and to ask for the docs when they are missing.
applies-when: The docs-guard trigger fires (docs or documented behaviour changed), or the PR adds behaviour that no document mentions.
not-when: The change is internal and no reader outside the code could notice it.
example: In invented PR 101 for owner/shop, the PR adds an env setting CART_MAX_ITEMS, and the README setup list does not name it. The reviewer asks for the setting to be added to the README.
mode: health, full
