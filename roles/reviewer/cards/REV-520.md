id: REV-520
rule: When no other rule applies, new code should follow the style of the existing code around it.
why: Google says the author should keep consistency with the existing code when nothing else decides, and the PHP standard gives the same reason: less strain when reading code by many authors.
applies-when: The PR adds code in a file or folder that already has a style for naming, layout or structure, and the new code does something else.
not-when: A written style guide or a tool setting of the project says otherwise, because it comes first.
example: In invented PR 101 for owner/shop, every other controller in the folder returns a resource class, and the new one returns a raw array. The reviewer names the pattern and the file and line.
