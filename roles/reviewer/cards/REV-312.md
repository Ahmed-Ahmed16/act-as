id: REV-312
rule: Every upload has a maximum file size, set in the validation.
why: OWASP says missing size limits let someone fill the disk with huge files. It names a size cap in the Laravel validation as 1 layer of protection.
applies-when: A changed route or form request accepts a file.
not-when: A file size limit is set for the whole route group and the reviewer has read it.
example: In invented PR 101 for owner/shop, the avatar rule is 'avatar' => 'image'. A user uploads a 2 GB file. The rule needs a max, for example 'image|max:2048'.
mode: security, full
trigger: When a changed route accepts an uploaded file
kind: source-advice
source: OWASP Laravel Cheat Sheet, Always Validate File Type and Size, https://cheatsheetseries.owasp.org/cheatsheets/Laravel_Cheat_Sheet.html#always-validate-file-type-and-size, read 2026-10-27 ; second source: OWASP File Upload Cheat Sheet, Upload and Download Limits, https://cheatsheetseries.owasp.org/cheatsheets/File_Upload_Cheat_Sheet.html#upload-and-download-limits, read 2026-10-27
