id: REV-105
rule: Lines in a deleted file stay counted. Do not treat a deleted file as one line.
why: The spec keeps lines in deleted files counted, so a deleted file adds to the cap like any other changed lines.
applies-when: A changed file is deleted in the PR.
not-when: none
example: In invented PR 101 for owner/shop, app/OldCart.php with 90 lines is deleted. It adds 90 counted lines.
mode: size, full
trigger: When a changed file is deleted
kind: user-policy
source: user decision, reviewer v1 spec, the size count rule, approved 2026-10-25
