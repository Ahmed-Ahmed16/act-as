id: REV-429
rule: Say what the independent check covered: "covers N picked tests". Never write that the tests are good.
why: The check looks at the picked tests only, so a claim about all tests would be more than the reviewer proved.
applies-when: Writing the result line of check H11.
not-when: none
example: In invented PR 101 for owner/shop, the check ran on 2 picked tests and both went red on the assertion. The line reads "covers 2 picked tests: clean", not "the tests are good".
mode: health, full
trigger: When writing the result of the independent check (H11)
