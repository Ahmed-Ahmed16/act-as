id: REV-402
rule: Run jscpd with the role's own reviewed settings file, given with --config. Never let a .jscpd.json from the PR set the scan.
why: jscpd picks a config file in a fixed order and a path given with --config is looked at first, so the role's settings come before a file the PR brings.
applies-when: Running the tool part of check H1.
not-when: none
example: In invented PR 101 for owner/shop, the PR adds a .jscpd.json that ignores app/Http. The run still passes the role's own file with --config, so app/Http is scanned.
mode: health, full
trigger: When choosing the jscpd settings (H1)
kind: source-advice
source: jscpd docs at tag v5.4.2, rust.md, Config file, https://github.com/kucherenko/jscpd/blob/v5.4.2/docs/rust.md#config-file, read 2026-10-27
