id: REV-604
rule: For a key passed to trans_choice, a language with the wrong number of plural forms is a finding of translation check 4. It is never must fix and never fails health. The script only counts the forms split by |. Compare its count with this card: en 2 (one, other), ar 6 (zero, one, two, few, many, other).
why: Unicode CLDR gives each language a fixed set of plural categories, and Laravel picks a form by position. When the chosen form is missing, Laravel returns the first form with no error, so a wrong count shows the wrong text silently.
applies-when: Running check T4 on a key that code passes to trans_choice, in a language listed on this card.
not-when: A | in a key that is not passed to trans_choice, such as a page title. Also a string with explicit range rules such as {0} or [1,19]: read it by hand, its count is not the CLDR count.
example: In invented PR 101 for owner/shop, the key "items_count" is passed to trans_choice and the ar text has 2 forms split by |. The card says ar has 6. Check 4 lists the key with the count per language. The reviewer confirms it and writes a finding. It is not must fix.
mode: health, full
trigger: When running translation check T4 (the wrong number of plural forms)
