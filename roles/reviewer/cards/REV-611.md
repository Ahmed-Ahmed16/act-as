id: REV-611
rule: When a new English text key matches the name of a translation file in the same language folder, point it out.
why: Laravel's docs warn against text keys that conflict with file names, and give the case: __('Action') for the nl locale, with a nl/action.php file and no nl.json, returns the whole contents of nl/action.php.
applies-when: A PR adds a JSON key, or a __() text, that equals a file name such as messages or validation under lang/ (the drafter's own narrowing: the page's example is a single word).
not-when: The project has no file of that name in the language folder.
example: In invented PR 101 for owner/shop, the PR adds the JSON key "messages" while lang/en/messages.php exists. The reviewer points at the clash and suggests a longer text.
mode: health, full
trigger: When a PR adds a JSON key that equals a translation file name
