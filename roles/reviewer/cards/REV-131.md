id: REV-131
rule: A generated copy is rebuilt in the same part as its source. Write it as 1 rebuild step with the command. It is not counted and it is not a part of its own.
why: The user wants a generated file never to sit apart from the source it comes from. Reviewing the copy line by line adds nothing, and a copy in a later part would be stale or missing in the earlier one.
applies-when: A changed file is a copy built from a source file, such as a compiled CSS or JS file, and the source also changes (full mode step 2, sub step e).
not-when: The copy changes and its source does not. Then link the copy to its unchanged source file at the frozen head and record the command used to check that file (full mode step 2e); it still gets its rebuild command.
example: In invented PR 101 for owner/shop, public/assets/admin.js is built from resources/js/admin.js. Both change for the refund screen. The copy goes in the refund part, with the line "rebuild: npm run build".
mode: full
trigger: When a changed file is a generated copy of a changed source
