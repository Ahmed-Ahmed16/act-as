id: REV-108
rule: The size line shows the verdict, the counted lines, the cap of 300, and, for each left out kind (tests, lock files, generated, docs), its lines and its number of files.
why: The user wants to check the count himself, so the line shows what was counted and what was set aside.
applies-when: Writing the size line of any packet that has a size count.
not-when: A single mode run that is not size. Its size line says "not asked" with no counts.
example: In invented PR 101 for owner/shop, the line reads "size: pass, 212 counted lines, cap 300; left out: tests 140 (3 files), lock files 0 (0 files), generated 0 (0 files), docs 12 (1 file)".
mode: size, full
trigger: When writing the size line
