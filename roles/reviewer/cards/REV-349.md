id: REV-349
rule: Read every new package: is it needed, does it come from the official source, and is it still maintained.
why: OWASP says to remove unused components, to take components only from the official source and over a secure link, and to watch for libraries that are unmaintained.
applies-when: A PR adds a package to composer.json or composer.lock.
not-when: The PR changes no package.
example: In invented PR 101 for owner/shop, the PR adds a package to format a phone number. The same job is done by a package the app already uses, and the new one has had no release for 4 years.
mode: security, full
trigger: When a PR adds a package
kind: source-advice
source: OWASP Top 10 2021, A06 Vulnerable and Outdated Components, How to Prevent, https://owasp.org/Top10/2021/A06_2021-Vulnerable_and_Outdated_Components/#how-to-prevent, read 2026-10-27
