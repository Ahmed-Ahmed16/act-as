id: REV-310
rule: Never pass request input to ignore() in a unique rule. Pass the id of the model you already loaded.
why: Laravel says only a system generated id, such as the key of a loaded model, may go into ignore(). Request input there makes the app open to SQL injection.
applies-when: A changed validation rule uses Rule::unique(...)->ignore(...) or the string form unique:table,column,id.
not-when: The value comes from a model the code loaded, or from the route model binding.
example: In invented PR 101 for owner/shop, Rule::unique('users')->ignore($request->id) lets a request supply the id. The safe line is ignore($user->id) with $user loaded from the route.
mode: security, full
trigger: When a changed unique rule uses ignore
