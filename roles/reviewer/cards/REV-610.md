id: REV-610
rule: With English text as the key, editing the English text makes a new key. The Arabic stays under the old key and the page shows the new English with no error. State this as a fact when a PR edits such a text.
why: The English text is the key, and a missing key shows the key. So the edit loses the link to the Arabic, and nothing warns.
applies-when: A PR edits an English text that is used as a key in JSON files, in code or a language file.
not-when: The project uses short keys in PHP files. There an edited value keeps its key and its other languages.
example: In invented PR 101 for owner/shop, the PR changes __('Order shiped') to __('Order shipped') and en.json to match. ar.json still holds "Order shiped". The key "Order shipped" has no Arabic, so Arabic readers see English.
