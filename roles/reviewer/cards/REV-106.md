id: REV-106
rule: A file under public/ counts as a generated copy only when its git blob id equals the blob id of a file outside public/. A copy that differs by even 1 byte is counted.
why: The spec says a file under public/ is generated only when it is a byte for byte copy of a source file, and a copy that differs by 1 byte is counted because someone edited it by hand. Git blob ids are how the counter compares bytes.
applies-when: A changed file sits under public/ and may be a built copy of a source file.
not-when: The file is already a generated path, such as public/build/.
example: In invented PR 101 for owner/shop, public/js/app.js has the same blob id as resources/js/app.js, so it is left out. If someone edited 1 byte by hand, it is counted.
mode: size, full
trigger: When a changed file sits under public/
