id: REV-329
rule: Session cookies carry the HttpOnly flag, so scripts cannot read them.
why: OWASP says to enable http_only in the Laravel session config so JavaScript cannot reach the cookie, and calls it a mandatory protection against stealing the session id after an XSS bug.
applies-when: A change touches config/session.php or sets a cookie by hand.
not-when: The cookie is not a session or login cookie.
example: In invented PR 101 for owner/shop, config/session.php gets 'http_only' => false for a script that needs the cookie. An XSS bug on any page now steals the session.
mode: security, full
trigger: When a changed file sets a session cookie flag
kind: source-advice
