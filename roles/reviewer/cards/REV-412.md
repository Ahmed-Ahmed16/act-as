id: REV-412
rule: When no test covers a risky area, report that as a finding of its own: "no test found by name, route or caller".
why: The spec wants a missing test to be a visible finding, so that an area with no test is never hidden by a quiet pass.
applies-when: A risky area (money, logins, deleting data, plus the business step's risky areas) has no test after the search.
not-when: none
example: In invented PR 101 for owner/shop, the PR changes refund logic. No test calls it by name, route or caller. The finding reads "no test found by name, route or caller", with the search that was run.
mode: health, full
trigger: When no test covers a risky area (H6)
