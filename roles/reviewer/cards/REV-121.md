id: REV-121
rule: Routes come from the files under routes/ that bootstrap/app.php loads. Read bootstrap/app.php first, then the route files it names.
why: Laravel says all routes are defined in the route files, and that bootstrap/app.php loads them. So that file tells you which route files are real.
applies-when: The split step lists the routes of a Laravel project to find entry points (full mode step 2, sub step b).
not-when: none
example: In invented PR 101 for owner/shop, bootstrap/app.php loads routes/web.php and routes/console.php. A changed routes/web.php.bak is named nowhere, so it is not a source of routes.
mode: full
trigger: When listing the routes that really load
kind: source-advice
