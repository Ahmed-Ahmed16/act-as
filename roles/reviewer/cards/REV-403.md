id: REV-403
rule: Read how many files jscpd scanned. A scan of 0 files is "not checked", never "clean".
why: jscpd exits 0 after a scan that read no files, so a clean looking exit says nothing about code it did not read.
applies-when: Reading the jscpd result in check H1.
not-when: none
example: In invented PR 101 for owner/shop, the scan path holds no PHP files. jscpd prints a warning and exits 0. The reviewer writes "not checked: jscpd scanned 0 files".
mode: health, full
trigger: When reading the result of the jscpd scan (H1)
kind: source-advice
source: jscpd docs at tag v5.4.2, rust.md, Exit codes, https://github.com/kucherenko/jscpd/blob/v5.4.2/docs/rust.md#exit-codes, read 2026-10-27
anchor: "still exits 0, so an intentionally empty tree does not break a pipeline"
