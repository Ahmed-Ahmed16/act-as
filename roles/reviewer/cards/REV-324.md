id: REV-324
rule: A password reset checks a token that is random, tied to a single user, and no longer valid once it is used.
why: OWASP lists the rules for reset tokens: a secure random value, long enough, linked to a single user, and invalidated after use.
applies-when: A change adds or edits a password reset or account recovery flow.
not-when: The framework's own reset code is used unchanged.
example: In invented PR 101 for owner/shop, the reset link holds the user id and a date, with no random token. Anyone can guess the link for another user.
mode: security, full
trigger: When a changed flow resets or recovers an account
kind: source-advice
source: OWASP Forgot Password Cheat Sheet, General Security Practices, https://cheatsheetseries.owasp.org/cheatsheets/Forgot_Password_Cheat_Sheet.html#general-security-practices, read 2026-10-27
anchor: "Invalidated after they have been used"
