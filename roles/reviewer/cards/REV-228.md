id: REV-228
rule: Write a grill draft page only to the drafts folder (the one the private overlay names, else rules-drafts-<owner>-<repo> next to the checkout). Refuse any path inside the checkout.
why: The reviewer leaves the checkout exactly as it found it, and a draft in the checkout could be committed by mistake.
applies-when: Writing a draft rules page.
not-when: none
example: In invented PR 101 for owner/shop, the draft goes to ../rules-drafts-owner-shop/gifts.md. A path like docs/business-rules/gifts.md inside the checkout is refused.
mode: business, full
trigger: When writing a draft rules page
