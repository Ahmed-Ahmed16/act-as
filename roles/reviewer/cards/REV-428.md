id: REV-428
rule: The fault must contradict what the test asserts. Never use a syntax error. A probe command must show the behaviour before and after. If the probe shows no change, write "not checked: fault did not contradict the assertion" and do not condemn the test.
why: A fault that does not change the asserted behaviour says nothing about the test, so a green result then proves nothing in either direction.
applies-when: Writing the fault and probe for a picked test.
not-when: none
example: In invented PR 101 for owner/shop, the test asserts a discount of 10 percent. The fault changes a log message, not the discount. The probe shows the discount is the same. The result is "not checked: fault did not contradict the assertion".
mode: health, full
trigger: When writing the fault for a picked test (H11)
