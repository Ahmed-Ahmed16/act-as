id: REV-331
rule: Session cookies set SameSite to lax or strict, not none and not left to the browser default.
why: OWASP says to set same_site to lax or strict so the cookie is not sent in cross site requests. The Session Management sheet says not to rely on the browser default.
applies-when: A change touches config/session.php or sets a cookie by hand.
not-when: The cookie is not a session or login cookie.
example: In invented PR 101 for owner/shop, config/session.php gets 'same_site' => null. The browser default then decides, and it differs between browsers.
mode: security, full
trigger: When a changed file sets the same site cookie option
