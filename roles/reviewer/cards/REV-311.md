id: REV-311
rule: Store an upload under a name the app makes. Never trust the file name or extension the client sent.
why: Laravel says the client file name and extension can be tampered with, and tells you to use hashName() and extension() instead. OWASP says a random name such as a UUID is the safe choice.
applies-when: A changed line stores or moves an uploaded file.
not-when: The business needs the original name; then it is validated (length, allowed characters) and kept apart from the stored name.
example: In invented PR 101 for owner/shop, the code runs $file->storeAs('docs', $file->getClientOriginalName()). A user uploads ../shell.php or a file with a name that replaces another user's file. The fix is $file->store('docs') or a hashName() name.
