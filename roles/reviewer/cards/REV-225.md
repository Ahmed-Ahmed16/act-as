rule: If the PR adds new behaviour that no rule on the page covers, write a pointer with a draft question for the page.
why: A missing rule is a gap in the page, not a fault of the PR. Asking the question gets the page filled in.
applies-when: The PR adds behaviour in a touched area and no rule on the page is about it.
not-when: none
example: In invented PR 101 for owner/shop, the PR adds a limit of 3 gift wraps per order and no rule mentions wrapping. The packet has a pointer and a draft question: "How many wraps may one order have?".
mode: business, full
trigger: When new behaviour has no rule on the page
