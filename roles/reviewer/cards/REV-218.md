rule: If the PR leaves a gap rule alone, write it as a pointer, not as a finding.
why: Only what got worse should fail. An old gap is still worth a note for the reader.
applies-when: A rule marked gap, and the PR does not touch the code it is about.
not-when: none
example: In invented PR 101 for owner/shop, R10 (gap) is untouched by the PR. The packet lists R10 under Pointers with the page path as reference.
mode: business, full
trigger: When the PR leaves a gap rule alone
