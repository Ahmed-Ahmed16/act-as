id: REV-303
rule: For a changed permission rule, think through its edge cases and look for a test of each: the owner, a user who is not the owner, and any allowed exception such as an admin.
why: Google tells reviewers to think about edge cases, not only the main path. OWASP says to write tests that show the authorization works, and to not ship a change that makes them fail.
applies-when: The PR adds or changes who may do an action.
not-when: The PR does not touch who may do an action.
example: In invented PR 101 for owner/shop, a policy now lets the owner and admins delete a comment. The tests only cover the owner. The reviewer asks for a test that a different user is refused and a test that an admin is allowed.
mode: security, full
trigger: When a PR changes who may do an action
