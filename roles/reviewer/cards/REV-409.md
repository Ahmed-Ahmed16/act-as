id: REV-409
rule: A relationship loaded lazily inside a loop over many rows is always a lead, never a finding and never must fix.
why: Laravel names this the N + 1 query problem and says eager loading eases it. How slow it gets depends on the number of rows, which the reviewer cannot see from the diff, so it stays a lead.
applies-when: A changed loop reads a relationship of each row.
not-when: none
example: In invented PR 101 for owner/shop, a loop over orders reads $order->customer on every row. The reviewer writes a lead: "possible N + 1 at OrderExport.php:40, load customer first?" and does not mark it must fix.
