id: REV-204
rule: Read only plain files and folders in a Covers line, comma separated, a folder ending in /. Do not read an entry with a wildcard or other pattern: write "not checked: Covers entry is a pattern" and make that area incomplete. The plain entries on the same line still count.
why: Ahmed settled in B15 that entries are plain paths. A guessed pattern match could map a file to the wrong area, so a pattern is never expanded.
applies-when: A Covers line holds an entry like app/Orders/* or app/**/Cart.php.
not-when: none
example: In invented PR 101 for owner/shop, the line reads: Covers: app/Orders/, app/Cart.php, app/Shipping/*. The first 2 entries count. The reviewer writes "not checked: Covers entry is a pattern" for the third, and the area is incomplete.
mode: business, full
trigger: When a Covers entry holds a wildcard or pattern
