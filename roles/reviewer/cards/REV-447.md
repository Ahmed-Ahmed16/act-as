id: REV-447
rule: Read every touched file whole, not only the changed lines, when answering review questions 11, 16 and 18.
why: The spec wants health to read the whole touched file, because a small diff can hide a copy or a mess that sits just outside it.
applies-when: A PR touches a file in a health run.
not-when: none
example: In invented PR 101 for owner/shop, the PR adds 5 lines to OrderService.php. Read whole, the file already holds the same discount rule in another method. Only the whole file shows the second copy.
mode: health, full
trigger: When reading the files a PR touched
