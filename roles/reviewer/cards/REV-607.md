id: REV-607
rule: Every raw output of a translation, {!! __() !!}, is a pointer. Open each one and check that every value inserted into the text is escaped. Say which value is not. It never fails health.
why: Blade's normal output is escaped, and raw output skips that. Laravel warns to be careful with content that users supply, so a translation printed raw is safe only if each value put into it was escaped first.
applies-when: Running check T7 on a changed Blade file that prints a translation with {!! !!}.
not-when: none
example: In invented PR 101 for owner/shop, a view has {!! __('Hello :name', ['name' => $customer->name]) !!}. The name is not escaped and a customer can set it. The reviewer writes a pointer that names the value $customer->name.
mode: health, full
trigger: When running translation check T7 (raw output of a translation)
