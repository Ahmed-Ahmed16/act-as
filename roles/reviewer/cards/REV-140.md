id: REV-140
rule: The draft message to the author opens with the size sentence and ends with the ask: "open part 1 first; each part gets its own review." It never says looks good.
why: Google tells a reviewer to ask the author to split a change that is too large into smaller changes that build on each other. A description should also say what is wrong or limited, so the message states the size and what was not reviewed.
applies-when: The split step writes the draft message of a short packet or of a review it anyway run (full mode step 2, sub step j).
not-when: none
example: In invented PR 101 for owner/shop, the draft says "This PR is 640 counted lines; the cap is 300. It was not reviewed past size." and ends "open part 1 first; each part gets its own review."
mode: full
trigger: When writing the draft message to the PR author
