id: REV-401
rule: The tool part of the copied logic check reports only clones that are new compared with the comparison base. Run jscpd with its base ref set to the comparison base and zero new clones allowed.
why: jscpd's own advice is to gate on new duplication and not on a total threshold. Copies that were already there are not this PR's doing, and a tool hit alone is never a finding.
applies-when: Running the tool part of check H1.
not-when: none
example: In invented PR 101 for owner/shop, the repo already holds 3 copied blocks and the PR adds a 4th. The run against the comparison base reports 1 new clone, and the 3 old ones are not reported.
mode: health, full
trigger: When running the copied logic tool (H1)
