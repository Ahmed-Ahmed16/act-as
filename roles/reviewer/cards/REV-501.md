id: REV-501
rule: Do not add a layer, interface, flag or setting that no caller needs today.
why: Google tells reviewers to watch for code made more generic than it needs to be, and Fowler says a feature built early is likely to turn out wrong.
applies-when: The PR adds an interface, a base class, a wrapper layer, a feature flag or a config setting.
not-when: A caller in the PR or the repo already uses each option the new piece offers.
example: In invented PR 101 for owner/shop, the PR adds a DiscountStrategyInterface with 1 class behind it and no second user. The reviewer asks which caller needs the interface today and writes it as a finding with the file and line.
