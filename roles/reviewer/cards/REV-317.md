id: REV-317
rule: A link or src address built from user text needs a check of its scheme, with a short list of allowed ones such as http and https. Escaping does not stop a javascript: link.
why: OWASP says Blade escaping does not check URL schemes. Its XSS rules summary advises that an untrusted URL in an href or src be limited to http and https.
applies-when: A changed view puts a variable into href, src or a similar attribute.
not-when: The URL is built by the app from fixed parts and only an id comes from the user.
example: In invented PR 101 for owner/shop, the profile page prints <a href="{{ $user->website }}">. A user saves javascript:alert(1) as the website. Escaping does not change it, so the click runs the script.
mode: security, full
trigger: When a changed view puts user text in a link address
kind: source-advice
