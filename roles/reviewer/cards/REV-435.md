id: REV-435
rule: Call env() only inside config files. In any other code read the value with config().
why: After config caching, env() returns only real system environment variables. A call outside a config file may then return nothing in production.
applies-when: Changed PHP code outside the config folder calls env().
not-when: none
example: In invented PR 101 for owner/shop, a service class calls env('PAYMENT_MODE'). It works locally. After php artisan config:cache in production it returns nothing. The reviewer reports it.
mode: health, full
trigger: When env() is used in changed code outside config files
kind: source-advice
source: Laravel 12.x docs, Configuration, Configuration Caching, https://laravel.com/docs/12.x/configuration#configuration-caching, read 2026-10-27
