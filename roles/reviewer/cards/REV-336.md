id: REV-336
rule: A file path built from request data is cut down to a plain file name with basename and stays inside 1 allowed folder.
why: OWASP shows that a filename taken from a request can hold ../ and reach files such as .env. It says to strip directory information with basename.
applies-when: A changed line builds a file path from request data for download, file, Storage or file_get_contents.
not-when: The path comes from the database or from fixed parts and no request value is in it.
example: In invented PR 101 for owner/shop, the report download runs response()->file(storage_path('reports/') . $request->name). A user sends ../backups/db.sql and downloads a database dump.
mode: security, full
trigger: When a changed line builds a file path from request data
kind: source-advice
source: OWASP Laravel Cheat Sheet, Do Not Rely On User Input To Dictate Filenames or Path, https://cheatsheetseries.owasp.org/cheatsheets/Laravel_Cheat_Sheet.html#do-not-rely-on-user-input-to-dictate-filenames-or-path, read 2026-10-27 ; second source: OWASP Laravel Cheat Sheet, Path Traversal, https://cheatsheetseries.owasp.org/cheatsheets/Laravel_Cheat_Sheet.html#path-traversal, read 2026-10-27
