id: REV-234
rule: A rerun reads the base commit and the default branch commit named in the identity line, never a newer default branch head.
why: The rerun then compares like with like. A newer default branch head could hold other pages or other code than the first run read.
applies-when: Running the page tool again for a rerun.
not-when: none
example: In invented PR 101 for owner/shop, the default branch has 3 newer commits. The rerun still reads the default branch commit written in the identity line.
mode: business
trigger: When a business rerun reads its commits
kind: user-policy
source: user decision, reviewer v1 spec, the rerun business rules, user story 87 (first half) and the rerun contract, approved 2026-10-25
