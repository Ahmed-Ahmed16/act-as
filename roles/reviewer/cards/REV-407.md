id: REV-407
rule: Count the route lines for each controller the PR touches. 10 or more route lines on 1 controller make a pointer. 9 or fewer do not. The count is never a finding.
why: The spec sets 10 as the line where a count becomes a pointer (B15), and a count alone never decides a verdict.
applies-when: A PR touches a controller and a route file lists routes for it.
not-when: none
example: In invented PR 101 for owner/shop, OrderController has 14 route lines. The count is a pointer, so the reviewer writes 1 line of judgement and asks the questions named in REV-450.
