id: REV-448
rule: Report only what the PR added or what it left behind in an area it touched. A problem in an untouched part of the same file is not reported. Write "PR added it" or "PR left it in a touched area" for each finding. If neither is true, drop it.
why: Reading the whole file finds old problems. The review is about this PR, so old problems far from the change are not its fault.
applies-when: A finding comes from reading a touched file whole.
not-when: none
example: In invented PR 101 for owner/shop, reading the whole file shows an unused method at the bottom that the PR did not touch. The reviewer drops it. A copy the PR added next to an old copy is reported as "PR added it".
mode: health, full
trigger: When writing a finding found by reading a whole file
