id: REV-326
rule: Logout ends the session on the server, not only in the browser.
why: OWASP says a web application must give the user a way to close the session, and must invalidate the session at least on the server side.
applies-when: A change adds or edits logout or session end code.
not-when: The framework's own logout code is used unchanged.
example: In invented PR 101 for owner/shop, logout only deletes the cookie. A copied session cookie still works on the server after the user logged out.
mode: security, full
trigger: When a changed flow logs a user out
kind: source-advice
source: OWASP Session Management Cheat Sheet, Manual Session Expiration, https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html#manual-session-expiration, read 2026-10-27
