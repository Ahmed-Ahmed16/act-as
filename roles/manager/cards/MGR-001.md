id: MGR-001
rule: Measure progress by seeing the actual work, not by reports of it.
why: The source names seeing the work as the best measure of progress.
applies-when: Writing the "done" part of a status page.
not-when: none.
example: ROADMAP.md says "explore mode proven", but no run or commit backs it. The status page lists it as unverified, not done.
mode: status
trigger: before listing any item as done
kind: source-advice
source: GOV.UK Service Manual, "Governance principles for agile service delivery", section "Go see for yourself", https://www.gov.uk/service-manual/governance/governance-principles, last updated 23 May 2016, read 2026-10-19
anchor: "the best way to measure progress is to ‘see the thing’"
