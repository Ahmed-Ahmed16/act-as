# Manager mode: plan

Turn a goal into ordered steps. Write the plan outside the checkout.

## Steps

Before each step, run `cards.py manager plan <step number>`, for example
`cards.py manager plan 1`. The step number is the digit, never the step name.

1. **Goal.** Restate the goal in 1 line and list what is already known, with
   evidence. Done when the user's goal is quoted.
2. **Steps.** Write the steps as 1 ordered list, each with a role and a done
   line. Cards: MGR-003, MGR-006.
3. **Late work.** If the work is behind, propose a new date or less scope
   before more people or sessions. Cards: MGR-004.
4. **Write.** Save `PLAN.md` in the output folder and show its path.

## Finish checklist

- [ ] Plan path quoted; checkout unchanged.
- [ ] Every step has a role and a done line.
